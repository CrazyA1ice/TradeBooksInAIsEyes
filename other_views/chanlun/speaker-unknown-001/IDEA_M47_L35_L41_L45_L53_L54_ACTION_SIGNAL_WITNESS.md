# M47 第五阶段｜已经存在的操作分歧，与尚未找到的同级相反订单

> 日期：2026-11-14。**非编号开放研究**，承接 [M47 第一阶段](IDEA_M47_SELECTION_CONSISTENCY_AND_PREFIX_STABILITY.md)、[第三阶段](IDEA_M47_L36_L40_L68_BOUNDARY_AND_POLICY_RECOMPOSITION.md)、[第四阶段](IDEA_M47_L36_L68_THREE_CENTERS_BOUNDARY_SWITCH_AND_BRANCH_SCOPE.md)。本报告核对缠中说禅第35/41/45/53/54课的整理版作者原文，与用户导出的凯翔A062/A073/A074/A085。没有取得新浪2007原始服务器字节，没有获得新知乎评论，不改用户答文，不取得2007分钟行情，不执行真实E1–E4市场实验；I82/KX-C46/v4.101.0不变，A016/A087、F01/OB38/OB99继续OPEN。

## 0. 本阶段究竟解决了哪个旧问题？

旧M47把目标设成极强命题：「同一时点、同一操作级别、同一市场前缀、不同**均合法**分解R1/R2，最后对同一笔账户可交割股份发出**相反的实际买卖命令**。」从第36课起已有**中枢价区差异**，第54课g7有**三卖标签差异、定性风险同向**，却没有满足这个强命题的源证。

本轮找到的第35课更精确：原作者亲自举例说明**同一路径、两个合法观察级别，买卖操作次数一方为2次往返、一方为无须操作**。因此「不同级别的行动计划确实可以不同」有了作者文本见证，不只是研究者数值玩具。第54课同一g1处又明说分笔视角会识别二类卖点，而1分钟视角只有两段、尚未形成该级别中心；第41课明说低级别信号若逆着未衰竭的大级别方向，参与会承担大级别继续运行风险。**仍然没有**证明同级两套R的反向订单。

报告区分五个不能跳跃的证据层：①类型/中枢标签；②某级别确认买卖点；③该操作级别针对当前账户的条件方案；④根据持仓/风控/可成交性发出的订单；⑤实际成交回执。只有①或②的分歧不自动生成④或⑤的互斥冲突。

## 1. 原作者的直接操作差异见证：第35课「5分钟2次往返 vs 30分钟无须操作」

[第35课作者整理正文，原发表2007-03-09 11:51:34](https://eczsc.com/originals/35)，讨论一个\`a+B+b\`及其下级别连接的**理论型示例**，明确说：

- 如果以**5分钟**操作级别读同一段上/下交替的局部连接，作者称它具有**2个底背驰、2个顶背驰、可以按买卖点完成2次完整操作**；
- 站在**30分钟**操作级别，同一段局部连接在文中**没有该级别买卖点，所以无须操作**；
- 作者紧接着强调选择级别受资金、T+1、手续费、反应误差、买卖点波幅等现实条件限制，并不意味着任何真实市场中较低级别一定成本后更好。

这是**AUTHOR_IDEALISED_CROSS_LEVEL_ACTION_WITNESS**，不是逐笔OHLC、真实盈利或本项目独立确认两个买卖点序列。整理文中“上下上三段”“2个底/顶背驰”的语言尚缺一张独立、连续且精确标点的同日原行情示图；不要机械推断仅凭三个粗线段便已逐一认证四次转折。作者的数量是**原文陈述**，不是我们的程序实测。

核心是操作级别不同：\`Signal_5m(P)\`与\`Signal_30m(P)\`不是同类型承诺，\`2次往返 vs 0次\`不推出“同一操作级别存在两个矛盾的合法R”。更不能把两个不同资金切片的行动视为同一账户库存上的相反订单。

**积极意义**：理论允许不参与一段小级别波动，能依据更大级别的计划继续持有/持币；这并不构成反对小级别交易者按各自计划操作的“行情预言错误”。

## 2. 第54课 g1：同一观察时刻的「较小级别二卖」与「1分钟尚无中枢」

[第54课](https://eczsc.com/originals/54) g0→g1：原文说当下到g1只有两段，在**1分钟构件视角**不形成该级别中枢；但**若分笔操作者**，g1可以构成第二类卖点。二者都在原作者同段明确论述中，说明\`SIGNAL_EXISTS(g_pen)\`与\`NO_1MIN_CENTER_YET\`可以并存。**不等于**\`CERTIFIED_1MIN_SELL=false\`已经具备完整该级别否定证书，更不等于一定有人在g1真正下了卖单；原图每一笔、下级段的完成首知和成交没有独立验证。

这例与第54课更后面的**g7**不同：g7是**两种高级中心组合对“是不是三卖”不同、作者认为后续定性风险一致**；g1是**操作显微镜不同，信号可见与不可见**。绝不可把这两个对照同时标成“同g合法R对应反向交易”。

## 3. 第41/53/45课使「没信号 = 不下单 = 持股」的偷换失效

[第41课（2007-03-30）](https://eczsc.com/originals/41) 说：小级别买卖点若与大级别尚未衰竭的方向相反，参与它会承担大级别走势延续风险；这是一条**上层约束/风险提醒**，不是作者给出小级别信号“根本不存在”的证书，也不是永远必须拒绝任何逆大级别的套利。可记\`LOW_LEVEL_SIGNAL_VALIDITY\`、\`HIGHER_LEVEL_DIRECTION\`、\`PARTICIPATION_RISK\`三项。

[第53课（2007-05-23）](https://eczsc.com/originals/53) 则说：第二、三类买卖点之间如果属于当前**该级别中心震荡**，这时**没有该级别买卖点**；若参与内部波动，实际用的是**更低级别的买卖点**。该节明确承认按更细级别操作有时间、交易费和资本容量限制。这给「同一振荡区间，高级别无点、低级别仍可有点」再添一份独立作者文本见证。

[第45课（2007-04-12）](https://eczsc.com/originals/45) 强调除了买入卖出，更常见是**持股与持币的等待状态**。因此\`NO_SIGNAL_30m\`并不自动规定\`HOLD_STOCK\`——若账户原来持币，维持状态就是\`HOLD_CASH\`；若持股并已有预先确定的本级计划，才可能是继续\`HOLD_STOCK\`。这个状态依赖账户持仓和执行权限。原第45课的“未来点绝对保证”属于作者理论断言，本报告不转成实盘期限/安全担保。

据此需区分：
\`MARKET_HAS_NO_CERTIFIED_SIGNAL_g\` / \`SIGNAL_PENDING\` / \`POLICY_HAS_NO_ORDER\` / \`ACCOUNT_HOLDS_STOCK\` / \`ACCOUNT_HOLDS_CASH\` / \`ORDER_REJECTED_OR_UNFILLED\`。
这些状态看起来都“没买卖”，但原理、证据和账户后果完全不同。

## 4. 凯翔回答的真实原句：偏偏不能从“顺大逆小”偷出一条自动冲突裁判

用户导出原始档案：[100答固定文本](answers-2026-11-11.md)；100条索引[见此](answers-index.json)，答者归属为\`USER_SUPPLIED_EXPORT_NOT_PLATFORM_VERIFIED\`，不是本轮新在线抓取。

- [A073《顺势交易系统真的有用吗？》](https://www.zhihu.com/question/460755177/answer/3558993032)：答主不是发布“只须顺大逆小”的机械律，恰恰问**大级别趋势究竟走完没有如何判断**；还指出即便只做涨/盘/跌分支，事后转向的判断可能出错。故不能用A073替第41课补一条“只要大方向一看空，所有小买点自动无效”的算法。
- [A085《你认为炒股最重要的是什么？》](https://www.zhihu.com/question/654388108/answer/3524620893)：答主列“周期选择（级别，即计划持股时间）、仓位管理、选股、买点、止损点、卖点”六要素及更宏观因素，这支持研究者从\`signal_g\`推进到\`operating_horizon + inventory + stop + execution\`，但本人**没有**提供跨R同时反向买卖的账户唯一仲裁函数。
- [A074《你们缠论怎么止损的？》](https://www.zhihu.com/question/659943842/answer/3544513740)：他说买入后下跌要审**当时结构解读是否正确**及后来是否破坏结构，解读错误或已破坏时止损。为避免后验改分解口径来取消认错，研究者建议把买入时\`g/R/C/source/asof\`冻结供检查；但这是**研究者的审计协议**，不是A074公开的资金止损公式。
- [A062《从级别方面看线段和走势类型有什么区别？》](https://www.zhihu.com/question/434662413/answer/53263874696)：答主给“最低级别底层段是构件”与“更高级别视角下段可作为走势类型”的两层用语；这增强术语对象匹配必要性，但**不能**把A062当已证明某一R的完整合法解析，也不等于他已公布A087第二中心公式。

**结合**：凯翔A085的“级别/计划持股时间”加原第35/45课，让“无交易”成为与**操作合约/持仓状态**有关的结果，而非只看中枢标签就能填入\`BUY\`或\`SELL\`。A073提醒“顺大逆小”本身需要结构未完确认，不可为了消除争论而伪造机械优先级；A074要求决策后可追问当时为何买入，这反而支持保留历史\`R\`证据。

逻辑误用：\`L0\`≠\`L3\`，\`L1\`≠\`L3\`，\`L2\`只是风险门，不直接修改\`L0/L1\`的结构真值。\`NO_SIGNAL\`也绝非\`SELL\`；\`BUY_CANDIDATE\`在持有股份且满仓账户下不等于立即可多买。

### 两个研究者条件对照（非历史事件）

**情形A：同一路径不同操作层**。假定有5分钟短差的两次往返与30分钟主仓不动，如第35课作者理论例子；若只有一个账户，有足够可分配股份，\`5m-slice=30股\`、\`30m-slice=70股\`，5m轮动与30m保留70股可以并行，**不是同一股份冲突**。但这30/70仅是假设策略配置，不是第35课原作者设定仓位，也不是已验证盈利。若主仓实际一股都不能卖，5m分支则不能无授权卖出共享库存。

**情形B：真正强冲突需要额外什么？** 固定同一时点t、同一操作g、同一账户一份股票，两个**独立获证合法的**R分别触发\`SELL(share1)\`与\`HOLD(share1)\`，这已属**不同订单/状态规划**而不是直接\`BUY vs SELL\`；若一方\`BUY(share1)\`另一方\`SELL(share1)\`且双方对同一份库存可执行、同一策略任务同时生效才是L3待证核心。即便两种方向信号均能出现在不同g，也不能填补这里缺少的“同g / 双合法R / 两套完整条件计划”源证。

## 6. 真正能结束悬案的新材料与失败条件

- **优先查原作者**：找出同一个\`asof\`、\`g\`、\`stock\`、\`R1/R2\`均合法，且在相同资金任务下**明确说要一边买一边卖**的案例；必须记录中枢/段成员、两个规则的应用资格与首知，不把第35课跨级不同交易次数偷作答案。
- **其次是第35课图谱数目**：确认原作者“上下上三段/2个顶2个底”的粗线段表述如何对应具体a+B+b完整端点；若文本有不同编辑异文，必须分来源存，不对作者概念错误先下结论。此项仅做史料精度审查，**不重启历史分钟采购**。
- **检验第41/53课**：真实前缀下一小级别买点如何判断大级别“尚未衰竭”\`first_known\`；政策改变发生在信号之前还是之后？没有完成证书就\`PENDING\`，不假装风险过滤器具有未来知识。
- **对A074/A085的验证**：从已授权账户模拟（不是实盘）试验，在固定5m/30m持仓切片和同一笔股份库存约束下是否产生订单覆盖；不能把模型编成原作者交易指令。

**阶段断言**：\`AUTHOR_CROSS_LEVEL_ACTION_DIVERGENCE_CONFIRMED_IN_TEXT\`，\`SAME_LEVEL_LEGAL_R_OPPOSITE_ORDER_WITNESS_NOT_FOUND\`，\`ACTUAL_TRADES_NOT_VERIFIED\`。这里的“confirmed”只指整理版**作者文本**明确说过，不是市场算术/复现证明。I82/C46、A016/A087开放状态不变，原用户凯翔100答不修改。
