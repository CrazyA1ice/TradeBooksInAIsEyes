## 核心发现 1：回收本金 ≠ 经济风险归零

第31课的‘零成本股票’方法要求卖出一部分持仓回收初始投入，再继续持股。一个合成现金流账本可以清楚地说明：以1000元买100股；涨到20元时卖50股回收1000元；保留50股价值1000元。后续跌到4元，剩余股份仅值200元。

尽管最初本金已回收，**持仓剩余价值依然从1000元跌去800元**。不能将个人内部账本的‘成本=0’说成剩余股票无风险。第26课的资金期限和交易中断约束也同样适用。

[现金流和风险的数学审计](../../../../experiments/protocols/chanlun_lesson031_zero_cost_basis_audit.md)。

## 核心发现 2：“按当下定义交易”仍需防止未来知识

第32课认真地提出：a+A+b+B+c 中，出现 A 不保证出现 B；B 或 c 是否形成要随行情重新判断。这比事后固定预测更加谨慎。

但**走势实际发生、走势可被确认、最早能够完成订单的时间**仍不同。第33课又指出因采样精度、级别延伸以及多种合法解释，相同历史可能有多个分段版本。在当下选取某个分段时，必须记录它何时形成以及选择依据，不能在看到未来后选“表现最好”的版本。

## 核心发现 3：第35课回应循环定义，却不自动证明唯一分解

第35课是目前最重要的定义版本补充之一。作者明确承认：没有最低级别，中枢和走势类型会互相引用，导致循环。为此，他从最低级别成交与同价三笔、中枢和走势类型的递归关系出发，并提出两个分解定理。

“连接满足结合律而不满足交换律”在底层成交序列**拼接**的意义上确实成立：

```text
(A + B) + C == A + (B + C)
A + B 一般不等于 B + A
```

但字符串或成交序列拼接不改变底层顺序，并不自动证明把它们分成中枢、趋势等高阶标签的方式也是唯一的。第33课的多义性要求在分段识别器中允许多个合法解析，不可事后只保留有利于收益的解析。

更需警惕：第35课的“连续三笔同价成交”基例是否在任意真实逐笔数据中都会出现？若没有出现，递归如何启动、如何分类？**给出基例解决了相互引用的一个环节，但尚需验证全定义性、终止性、歧义处理和可运行性。**

[递归基例与结合律审计](../../../../experiments/protocols/chanlun_lesson035_recursive_decomposition_audit.md)。

## 核心发现 4：更小操作级别未必更有交易优势

第35课明确指出实际 T+1、费用和执行误差让很低的操作级别不可随意采用，这是对前面“越精细越好”印象的重要限定。若一次交易预期价格波幅很小，成交时间差、买卖价差、费用可能侵蚀全部名义利润。

因此，今后知识库需要把定义级别、观察级别与实际可执行操作级别分为三个独立字段。

## AI 研究主张

将缠论知识库中的每项核心定义保存成一个**版本化、有前提的逻辑对象**，至少包括：

- 来源卷号、页码、原文发表时点与后附问答时间层；
- 定义的依赖与递归基例、可计算表达、冲突/澄清关系；
- 同一历史是否存在多个合法解析；
- 信号首次可确认时刻、是否受真实交易制度约束；
- 纯形式验证结果与真实行情实证结果（不能混用）。
