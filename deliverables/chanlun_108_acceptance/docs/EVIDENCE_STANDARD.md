# 证据、可追溯性、版权与结论边界（v1.0）

## 主张类型

| 类型 | 使用条件 |
| --- | --- |
| `SOURCE` | 有可定位出处，忠实转述原作者 |
| `INTERPRETATION` | AI 对已定位原文提出的解释 |
| `INFERENCE` | 从已声明前提推导出的判断 |
| `HYPOTHESIS` | 可能成立但未被有效检验的观点 |
| `EVIDENCE` | 原始观察、引用资料或具备范围说明的实验结果 |

对每个关键结论保存：主张 ID、材料 ID、文件版本或哈希、所在 PDF 页、印刷页（如可核实）、章节/段落、图表区域（如适用）、研究版本及证据状态。页码不可用时如实注明。

## 可检验命题

每项研究记录可操作定义、检验范围、所需数据、可证伪条件、样本划分、成本和偏差控制，并保留负面结果。数据拟合效果不自动等同于因果解释或可复制交易收益。多次试验和更改参数须说明。

## 观点冲突与修订

冲突观点独立保存并建立关系，不用最新叙述覆盖历史。AI 观点改变时记录修订原因、新证据及原判断。信心标签仅表示证据充分程度，不提供伪精度百分比。

## 版权与隐私

该仓库目前公开。没有取得公开再分发许可的图书、扫描 PDF 或收费报告，**不要作为新文件提交到公开仓库**；使用私有存储处理。仅公开原创分析、合理必要的短引文及来源定位。已存在的 `ChineseBooks/缠论/` 五份 PDF 授权状态尚未核实，建立许可核对任务；本次初始化不改动文件。

本项目尚未选择原创成果的 LICENSE，添加许可证前应明确它只适用于相应原创内容，不应覆盖第三方书籍。

## 研究用途

作品属于研究与教育材料，不构成投资建议。任何实验结果必须提供条件、局限和时间范围；不得承诺盈利。
