# 第71课：同一特征序列的成员资格与线段局部确认

来源第四卷p.71–72，原始SHA-256 `ceca9ac8b7fb13106d2085253679acf1474373fb61ca38b487d8ca01cf0ad66d`。第71课说明：两个元素若不是**同一特征序列**里的正式成员，就不可讨论其包含合并；转折点后的某些分型右侧元素只属于帮助推导的AUXILIARY/UNDETERMINED状态。

本合成检查给每个特征元素显式标记`sequence_id`、`role`、价格区间与完成时间，只有两个`STRICT`成员且`sequence_id`相同才可能合并；异序列、辅助、待定元素均不能直接纳入已有标准特征序列。即便同序列，价格不相互包含也不能合并。

针对p.71–72描述的“从反向第一笔开始的新三笔”，只实现一个**人工指定方向的极简边界示范**：第一笔终点进一步被第三笔端点突破可视为局部新段条件、第一笔起点被反向先突破可判旧段可能延续，其间保持PENDING；第三笔未完成不得判定。真实规则还需各笔严格完成、序列标准化、有无缺口、后续反向特征分型、转折先后时序等，故程序不能称作已实现完整缠论线段。

还必须保存`extremum_time`和`confirmed_at`，后者不应早于实际支持判定的后续结构时刻。
