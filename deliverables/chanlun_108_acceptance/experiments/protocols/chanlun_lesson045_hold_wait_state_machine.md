# 第45课持股—持币—待确认的最小事件驱动模型

> 第三卷 PDF p.28–29，原始 SHA-256 `fad3474e103353f6f67799aefec8c9fba28c9615c0c77a5c67fcbf2b6b4f8a7a`。作者强调持股与持币的长期等待状态。

为了避免把“等待买卖点”错误写成“行情每根K线都要下单”，使用一个**只有单份假设持仓的合成程序**：

- 初始现金：HOLD_CASH；
- 已确认买点且成交：HOLD_STOCK；
- 已确认卖点且成交：HOLD_CASH；
- 未确认/PENDING 或执行失败：原仓位不变，记录无动作。

这不是一个自动生成缠论买卖点的系统，仅消费外部已确认标签；如果真实股票 T+1、部分成交、停牌或现金资产数量未核验，不得从模型得出安全交易保证。

[最小状态机代码](../../tools/audit_chanlun_lesson045_wait_state.py) 与单元测试通过后，才能讨论添加成交数量、成本、订单日志及到期风险。

**AI 结论**：可计算的‘不交易’状态是严格交易系统的重要组成部分。允许持股等待不等于仓位没有价格风险，允许持币等待不等于没有机会成本。
