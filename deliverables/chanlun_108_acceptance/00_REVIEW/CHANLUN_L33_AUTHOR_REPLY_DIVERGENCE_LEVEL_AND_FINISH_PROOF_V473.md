## 2. 必须显式分开的四种关系

设冻结观察层级、分解政策R及初始化f1；`D_h`=源规则认可的某h级背驰事件；`END_g`=g级走势真正完成；`KNOWN_g`=在t时首次凭合法完成证据能够确认。

| 命题 | 来源支持/限制 | 严格研究结论 |
|---|---|---|
| `D_g => END_g` | 第33课15:34作者回复中的**作者断言**（“至少结束该级别走势”） | 是**作者理论命题**，未给当下完成时钟和市场全域证明；不能写成“任意MACD金叉=当下已完走势” |
| `END_g => D_(g-1)` | 第33课明确**否定“必须恰好次级背驰”**这一要求 | 不能把它当作F01全域必要条件 |
| `D_(g-1) => END_g` | 由“某一级别背驰至少结束**该级**走势”**推不出跨到g级完成** | 即使观察到已确认的g−1背驰，也不得自动出具g级`COMPLETED_CHILD_MOVEMENT_ID` |
| `END_g => some D_h` | 作者口语所称“任何走势结束与背驰有关”，没有给遍及所有f1/R/g的严格量词或h到g映射 | 仅是**未全形式化的来源主张**；h范围、事件身份、完成证书仍OPEN |
| `D_g at t_price => KNOWN_g at t_price` | 回复未给“背驰实际发生”的历史价事件与“完整结构首次可知”之间的同刻定理 | **不得推出**；结构首知可能需要后继成员确认，须另保存`event_price_time`和`first_known_at` |

**修正v4.72后接推理**：对第100课C3或600216，不能因1分钟某个背驰就确认5分钟回拉/5分钟三买：至少需要已认证的完整1分钟回抽作为目标级别次级成员、合法中心与首次回试对象。若反过来**未检测出同一个g−1级背驰**，也不能据此全称否认g走势结束，因为作者否定它是唯一必需的触发层级。这两种错误对应充分性、必要性两种不同的方向偷换。

## 3. 第27课正式正文为“逐级缩小背驰段”的最下层精度提供限制

[第27课 AUTHOR_MAIN，2007-02-02 15:11:27](https://eczsc.com/originals/27)早于第33课回复。作者将趋势背驰与盘整背驰分开：趋势背驰至少要在第二个同级中枢之后；单个中心附近的弱势回落通常归盘整背驰，两种不能在未经语义审查时混成同一`D_g`谓词。同时作者把高层背驰段逐级定位到低层，看作**有限层级**嵌套式缩小：真实层级不无限细分，故**并不能保证得到数学上唯一的点状终点**。

这与“某级背驰至少结束该级走势”的**作者断言**并不等价：前者是有限层级与空间精度/信号定位的论述，后者是走势类型完成的因果声称。即使回放历史上最后一次成交恰为最低点，也必须分别追查**哪级背驰成立、对应类型是否完成、最早何时已知、何时能够下单**。不能把“区间套在历史上越缩越窄”冒充实时底部单价确认。
