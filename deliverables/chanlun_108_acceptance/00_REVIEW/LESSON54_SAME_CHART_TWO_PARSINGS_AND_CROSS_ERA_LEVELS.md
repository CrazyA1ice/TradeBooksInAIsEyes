## 2. 同一路径，两种作者许可的分解

### 2.1 到`d4`时

甲方案：

```text
g0d4 = g0d1 + (d1g1+g1d2+d2g2) + g2d3+d3g3+g3d4
```

乙方案：

```text
g0d4 = g0d1+d1g1+g1d2 + (d2g2+g2d3+d3g3) + g3d4
```

第54课说明作者认为这两种分解均可采用：甲方案带有从原中枢脱离、向新中心或更高级别中心过渡的**未决中间状态**；乙方案便于对当前中枢震荡进行操作分析。**但并非任意加括号都合法**：两个相邻同级别中枢之间必须存在合格的次级走势连接。无该连接的同级中心并列分法，作者明文排除。[CL54-SOURCE-2，卷三p.172](../../../knowledge/evidence/chanlun_lesson054.json)。

### 2.2 到`g5/g6`时，高一级别中枢的成立时点不同

甲方案作者正文写成：

```text
g0g5 = g0d1 + {
  (d1g1+g1d2+d2g2)
  +(g2d3+d3g3+g3d4)
  +(d4g4+g4d5+d5g5)
}
```

**甲方案**较高级别中枢：到`g5`形成；中心区间 **`[d2,g5]`**。

乙方案作者正文写成：

```text
g0g6 = g0d1+d1g1+g1d2 + {
  (d2g2+g2d3+d3g3)
  +(g3d4+d4g4+g4d5)
  +(d5g5+g5d6+d6g6)
}
```

**乙方案**较高级别中枢：到`g6`形成；中心区间 **`[d3,g5]`**。

这里第三行的符号是作者图示价格标记，不能当成日历或纯数学序号计算。三项分歧均由**作者正文亲自给出**。[CL54-SOURCE-4，卷三p.174—175](../../../knowledge/evidence/chanlun_lesson054.json)。这是明确的**原文同图双解**，不是AI合成的分歧。

**能推出**：不固定分解政策时，不能假定“同一图→相同中枢边界/相同首次形成位置/相同三卖标签”。

## 5. 六个“坑”放在同一张图中，真正指什么

1. **第17课前后涨/跌/盘定义变了**：第15课是经周期与均线过滤的高低点关系；第17课是**完成走势+该级别中枢数目**。两种谓词的输入对象都不同；不能从价格明显上升直接推出第17课上涨趋势。
2. **一个中枢仍可整体有方向**：盘整在作者后期是按**中枢数目**而非全段收益率命名；更要小心“中枢已形成”不等于“该走势已经完成为盘整”。
3. **35课严格级别≠实用时间周期的简单同义词**：第54课的分钟观察图和视次级为线段是**操作化约定**，非从第35课最低逐笔基例全部重建。
4. **小→大构造和大→小区间套不是同一算法**：第54课先选定观察级别、把次级段作假定构件；第72/84课才系统给出底层构造及两种递归函数的区别。若主张输出相同，必须额外证明。
5. **各级形式相似≠统计交易效果相等**：第54课本人还说此图1分钟某些盘整背驰操作意义不大，而在日线、年线意义不同；不能据此宣传每级交易命中率一样。
6. **原文并非不贴图**：第54课**原本含一张专门示意图**；真正难点是原书没有交付一套能对任意走势逐笔复算、冻结版本且裁决全部边界的标准解析器与图谱。

## 6. 得到的命题与证明界限

**已明确的AUTHOR SOURCE事实**：同一路径，甲乙两种作者许可分组在`g5/g6`中心形成时点、区间`[d2,g5]/[d3,g5]`与`g7`是否三卖上存在差异；作者同时排除无合法连接的任意分组。

**AI有条件推论**：`价格路径固定` 不蕴含 `分组政策固定`，更不蕴含 `中心边界固定`、`首次可知固定`、`三卖标签固定`。连接满足结合律不表示任意加括号后的每棵解析树都合法。

**尚未解决的证明义务**：原图和历史编者注的精细图证、真实底层合法走势完成证书F01、冻结同一`R_g`的普遍存在/唯一/当时可知OB38、不同`f1`与`f2`初始化的严格输出等价、第99课所有合法未来更高中心必然性OB99，以及市场统计效果。均不得以第54课文字例冒充已证明。
