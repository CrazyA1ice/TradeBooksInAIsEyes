# F01推进｜从第35课最低级别趋势结束规则，到真正不循环的走势完成证书

> **研究节点 v4.32.0｜2026-11-11**。此文不是第54课另一种造价分段、不是交易策略、也不是把22项通过的程序测试说成作者理论已证明。继[上一步找到的2007年作者答疑“盘整第三点／趋势背驰后回拉”](WHOLE_BOOK_AUTHOR_REPLY_COMPLETION_EXIT_EVENTS_AND_NONCIRCULAR_PROOFS.md)，本次**重新精读第35课最低级别递归定义，找到独立于高级别第三点的最低级别趋势退出条件**。并实现一个独立、可运行、明确标`STRUCTURAL_ONLY`的“完成证书输入合同”：检查三笔同价基例、N-th中枢不再创新高的**作者谓词身份**、三个完成次级类型价格交集、第三点边界、构件依赖无循环、首次可知不早于依赖。**它不验证真实原始成交记录的真实性，不生成完整走势类型，也不验证历史交易盈利。F01/OB38/OB99=OPEN，实盘NOT_RUN。**

## 1. 原文关键新增：第35课已经给最低级别趋势明确的结束方向谓词

[第35课原文（2007-03-09）](https://eczsc.com/originals/35)，[仓库`CL35-SO-2`与`CL35-SO-9`，卷二PDF物理p.291](../../../knowledge/evidence/chanlun_lesson035.json)，首先解决了“中枢定义需要走势、走势类型定义又需要中枢”的循环：

1. **最低原子：逐笔成交而不是一分钟K线。** 在作者指定的严格最低级别模型，连续三笔**同一价位**的交易构成一个最低级别中枢。`3 trades same price`是**中枢存在的构造规则**，不是“最低盘整于第三笔立即结束”的规则。
2. **最低级别走势分类：**一个最低中枢对应盘整类型；两个按高低排序的中枢对应上涨/下跌趋势类型；如果持续有新的中枢，趋势可继续延伸。
3. **作者给出的最低趋势停止条件：**当已经是最低级别**上涨**，出现后续第N个中枢（**N>2**）**不再高于**前一中枢（含相等或更低），作者说可判该最低上涨结束；最低下跌按相反方向比较——后续中枢**不再低于**前一中枢。

这是与第67课线段合法破坏、2007-08-21评论给出的上层趋势背驰后回拉、或者第54课g/d抽象线段**不同的结束证据路径**。因此不能再笼统说“作者连最底层何时结束也没有任何规则”，应说：**最低趋势有方向判据，最低盘整的独立、最早且完备终止条件尚未从这些原文推出。**

但这里有一个必须尊重的限制：第35课**说某中枢“不再高于”前一中枢，却没有在该段为任意重叠/延伸的价格区间明确写出一种可全定义的数字比较器**。原仓库证据卡`CL35-SO-9`已经特别注明这一点。因此我们锁定`Nth_CENTER_NONADVANCE`为作者的**条件谓词**，而不擅自把它简化成“高点低于前一高点”“中心低点低于前一低点”“ZG小于前ZG”三者中的任何一种。不能把未冻结的中心比较器当成可复现、唯一的实时结果。

## 2. 最核心的逻辑证明：证书图必须从有来源的原子向上，而不是让子结论请求父结论背书

从[第18课](https://eczsc.com/originals/18)、[第20课](https://eczsc.com/originals/20)与第35课组合，可定义三层**研究者形式输入合同**（不是作者写的软件接口）：

```text
原始逐笔事实 [需独立校验完整序列]
    └─→ 三笔连续同价 → 最低中枢存在
               └─→ 前后各中枢序列 + N>2 “不再更高/更低” → 最低趋势结束候选
                      └─→ 已完成的次级走势类型（另需完整历史证书）
                            └─→ 连续三段完成 + 价格交集 → 高一级中枢存在
                                  ├─→ 完整次级离开 + 完整首次回试 + 第20课ZG/ZD → 三买/三卖候选
                                  │      └─→ 盘整退出候选
                                  └─→ 本级背驰 + 随后回拉末中枢 → 趋势退出候选
```

最危险的潜在非法环是：

```text
高一级盘整已完成 → 第三点已经成立 → 回抽走势已完成
                                    ↑           │
                                    └───────────┘
```

**拒绝原因**：根据[第20课原文](https://eczsc.com/originals/20)，**第三类点本身先要求**完成的次级离开和首次回试；它不能作为证明其所需要的回试本身已经完成的唯一依据。如果引用关系形成环，所谓证书只是循环标签，不能增加任何原始证据。

此外，最低中枢存在不能自动把单中枢盘整升级为`FINISHED_MOVEMENT`；第67课严格段结束也不是走势类型完成。第35课的最低级别**上涨终结谓词只适用于已形成最低趋势且出现N>2的中枢序列**，不能滥用给“只有一中枢的盘整”出具终止证书。

## 3. 本轮确实实现了什么可执行的审核？

新增[机器合同](../../../catalog/chanlun_f01_completion_receipt_contract_v1.json)、[结构审计器](../../../tools/audit_chanlun_f01_completion_receipts.py)和22项专门正反测试。程序运行：

```text
python -B tools/audit_chanlun_f01_completion_receipts.py
python -B -m unittest discover -s tests -p "test_chanlun_f01_completion_receipts.py" -v
```

它的审核对象明确是**调用者提供、没有独立真实性背书的抽象证书图**，而非本仓库已下载真实市场的逐笔数据。可以另外用`--bundle path/to/claims.json`给待审结构，但返回的最强结果**永远只有`PASS_STRUCTURE_ONLY`**。

审核层次：

| 证据类型 | 结构审核通过的必要条件 | 被明确拒绝的伪推导 |
|---|---|---|
| `RAW_TRADE` | 同一输入流的身份、成交序号、十进制成交价；`root_verified=false`以表示未经来源独立验收 | 只给价格而宣称真实逐笔已认证 |
| `F1_CENTER` | **三个连续、相同价位**原子事件；形成价位正确；历史发生与首次可知不同字段 | 三笔K线、跨序号成交或一个中枢推出盘整结束 |
| `F1_TREND_NONADVANCE` | 前一中心与第N个中心相邻且`N>2`；上涨标`NOT_HIGHER`、下跌标`NOT_LOWER` | 研究者未经明确规则，就宣称某自选数值比较器已独立验证 |
| `FINISHED_MOVEMENT` | 必须有**本级别独立退出事件**作为直接依赖；只接受声明存在退出事件的结构收据 | 将笔破坏、合法线段终止或中枢存在直接当作完整走势；默认仍未认证 |
| `F2_CENTER` | 三个同一下级别、按成员序号连续的**已声明完成类型**；使用其区间`max(lows),min(highs)`，含单价退化交集 | 直接拿三个笔/线段当作三个完整次级走势，或没有交集却画中枢 |
| `THIRD_POINT` | 同级中心+已经声明完成的下级离开/首次回试；买回试低点`>=ZG`，卖回抽高点`<=ZD`，保留作者等号 | 未完成回试自证三买；破坏ZG/ZD时仍宣称第三点 |
| `PAN_EXIT` | 同一个中心的第三点，且证书时间晚于其所有子依赖 | 任何一笔反向、首次回试尚未完成就提前判盘整结束 |
| `TREND_EXIT` | **尚不接收其为已审证书种类**：需先开发独立背驰、回拉真实证据接口 | 单独MACD金叉、线段结束或文字断言直接替代作者所指本级别背驰+实际回拉 |

这是**验证器的必要条件检查**，不等于证书充分。尤其关于“首次回试”：连续的两个声明成员`n,n+1`可以核对局部邻接，却不能证明历史全过程里**此前根本没有另一次合法回试**；必须有完整历史与同一冻结解析政策才有资格认证“真正的第一次”。

## 4. 为何即使一个抽象收据图通过全部22项测试，也不能说真实缠论已被证明？

这是本轮从“工具验证”到“证明逻辑”新增的**归纳式结论**：

- 假定一个有限的上层证明图必须由下层收据单向产生，并且所有叶子都依赖**外部原始逐笔/原始K线来源**。该图可以完全没有环、每条时间不倒流、价位交集计算也正确。
- **但只要叶子的市场来源内容仍未验证**，图内部的结构逻辑不能凭自身对这些叶子真伪作出保证。沿依赖图按拓扑顺序归纳，任何上层认证也至多是“**如果这些叶子和退出声明为真，则本层形式条件相符**”，不可能仅靠结构图把未经认证的叶子升级成历史真实事件。
- 同样，**作者称某事件是走势终结标志**与**实际市场达到该事件的最早可知时点**不是同一结论。首次可知必须晚于所用的全部下级证据，包括背驰之后对最后中枢的回拉。

这不是证明“作者理论有逻辑反例”，而是**证明这类仅做结构审计的程序不能独立保证市场真实性**。因此验收输出始终显式`NOT_AUTHENTICATED`、`OPEN`、`NOT_RUN`。用于测试的几个小数字全部属于**明确虚构的测试输入**，不属于第54课航天机电的历史价格、分解或盈利记录。

## 5. 三个此前容易忽视的历史版与边界问题

**其一，第35课作者明确说以“逐笔交易”为严格最低级别，随后使用1/5/15/30分钟是为了操作简便的非严格近似。**所以不能把两种取值同叫“最低级别”，不冻结`f1`就要求证明同一输出。2007-10-07第84课又进一步容许初始化`f1`不同于上层递归`f2`。<escape>作者并没有因为两者可能不同就证明所有可能初始化在每个历史端点产生完全相同的信号。</escape>

**其二，第20课原文的第三点判定是“不跌破ZG／不升破ZD”。**按照字面数值不等式，买方低点`>=ZG`、卖方高点`<=ZD`，**恰好接触边界不等于已经越界**。这与作者第54课接受一个价位重叠边界的原意相容，但也不替代第20课的“第一次完整回试”限定。

**其三，第35课中“同级别走势类型分类/递归”是一项作者的强论述，而不是我们已经独立拥有一份对所有交易记录可运行的、带版本和时间戳的终止判据。**第18课允许只有一中心的盘整继续延伸，第84课容许不同最低初始化，所以这一整套命题最终要在明确`f1, f2, R_g`和完整原始事件流后方能展开完整存在/唯一性证明。

## 6. 精确缩小到的下一道证明关口

**已闭合（条件级别）：**底层三笔同价的存在条件；底层上涨/下跌趋势N>2中枢不再朝原方向前进的作者退出谓词身份；三完整次级走势交集生成上一级中枢的代数条件；第三类点`>=ZG / <=ZD`边界的必要检查；依赖图无环与事实首次可知不早于所依赖输入。

**仍OPEN（足以阻碍真实完全证明）：**

1. **B-EXIT-PAN**：仅有一个最低中枢的盘整，如何不借未来和自身结论证明它在哪个时刻**已经结束**？第35课尚未给出像最低趋势N-th不前进那样独立且全定义的结束时钟。
2. **B-NONADVANCE-COMPARE**：第35课称“新中枢不再更高/更低”的范围比较在各种退化/扩展情况下究竟使用何种数字算子？
3. **B-PREFIX-AUTH**：实际逐笔/子分钟输入流、完整性身份、冻结分解及各条件最早可知时刻。
4. **B-THIRD-FIRST**：第20课“第一次已完成次级回试”必须从完整历史中证明真正**首次**，不能由人为填写`first_retrace=true`决定。
5. **B-TREND-DIVERGENCE**：本级别背驰与后续实际回拉的可执行、非循环证明（涉及形态与动力学），现不能仅由笔段解析提供。

此前F01“缺完整走势完成证书”的问题，至此已经不是泛称“没有规则”，而是**底层单中心盘整出证／最低趋势比较器／真实第一回试验真／回拉背驰验真这四种具体缺口**。与第54课同图跨时代分解是否可机械复现，仍为不同问题，不能因本轮有图结构校验通过就宣称二者等价。
