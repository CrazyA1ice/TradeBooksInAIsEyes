# 《缠论》G01/G05：第一次真正生成局部候选，而不是人工声明结果

> 研究定位：本轮复用现有第67课局部分型/缺口分类器与第71课严格成员检查，组合为G01局部候选生成器；G05采用**外部明确声明的准入片段表**进行穷举，产生全部允许的切分候选。这是有限的AI研究机制，不是完整原作者线段语法，也不是作者第38课分解唯一性证明。不使用原PDF图像或市场行情。

## 新增的实际计算能力

**G01的输入**为三项按先后排列、已经预标准化的合成特征元素，包含区间、严格/辅助身份、同一序列ID、确认时间，以及可选的后续反向分型观察时点。代码先用第71课的类型边界限制成员资格，再使用第67课的三项极值比较和第一二项的缺口关系计算局部候选。对于有缺口路径，只有反向确认已出现在`as_of`时点之前才产生局部候选。**这是局部终结条件，不是完整线段完成证明。**

**G05的输入**是已经结束或尚未结束的长度为n的合成历史以及一个`allowed_spans`表，表中每个`[start,end]`表示研究者**外部假定**某区间可作为一段。工具以这些区间为边，通过穷举而非贪心，计算每一条从0至n的完整覆盖路径，并列出全部分界点。它能够区分无可行切分、唯一候选和多个候选，还去重重复声明的片段。**准入表没有由作者完整规则生成，因此候选数量只是该表下的局部事实。**

## 计算样例与条件

| 案例 | 研究输入与预期 | 局部结果 |
|---|---|---|
| G01-R01 | 67局部分型无缺口可以生成候选，但不是已认证线段。 | `LOCAL_NO_GAP_NOT_SEGMENT_CERTIFIED` |
| G01-R02 | 有缺口局部候选必须继续等待反向确认。 | `PENDING_OPPOSITE` |
| G01-R03 | 有缺口且反向证据到达，才生成局部候选。 | `LOCAL_GAP_NOT_SEGMENT_CERTIFIED` |
| G01-R04 | 辅助成员不允许冒充严格特征序列成员。 | `INVALID_STRICT_MEMBER` |
| G01-R05 | 候选第三成员尚未在as-of时刻得到确认。 | `FEATURE_NOT_YET_ASOF` |
| G01-R06 | 不满足67课的三成员顶部关系，应拒绝候选。 | `NOT_EXPECTED_FRACTAL` |
| G05-R01 | 同一外部准入表产生两个切分候选，不能宣称作者反例。 | `MULTIPLE_PARSES_UNDER_EXTERNAL_SPANS`；切点 `[[1],[2]]` |
| G05-R02 | 限定准入表只有一份切分，并非对所有输入唯一。 | `ONE_PARSE_UNDER_EXTERNAL_SPANS`；切点 `[[2]]` |
| G05-R03 | 外部准入表无法覆盖全长，存在性没有建立。 | `NO_PARSE_UNDER_EXTERNAL_SPANS`；切点 `[]` |
| G05-R04 | 未完成历史不应提前枚举最终规范型。 | `WAIT_COMPLETE_INPUT`；切点 `[]` |
| G05-R05 | 重复声明同一候选片段不能伪造两份不同分解。 | `ONE_PARSE_UNDER_EXTERNAL_SPANS`；切点 `[[2]]` |

其中最值得重视的是`G05-R01`：在同一声明表里允许`[0,1]+[1,4]`和`[0,2]+[2,4]`时，算法输出两套完整分界点`[1]`和`[2]`。如果采取“找到第一条切分就停”的贪心搜索，会漏掉第二种解释。它展示的是为什么研究**唯一性**必须首先有**穷尽的合法候选生成器**；但由于这些区间是研究者假定，不构成作者理论已被反例推翻。

`G01-R02`与`G01-R03`使用同一组局部有缺口区间，只改变反向信息何时可知：前者保持待定，后者在确认时间后出现局部条件。这里把**最终有证据**与**当下有证据**分开，避免将事后图形倒填为即时可交易信号。
