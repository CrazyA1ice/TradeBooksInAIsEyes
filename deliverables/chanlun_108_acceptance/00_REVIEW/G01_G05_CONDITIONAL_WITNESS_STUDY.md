# 《缠论》G01/G05 双关口：从抽象证明缺口到条件性边界情境

> **本报告仅使用已存SOURCE证据卡和合成假设。** 这里的十个情境是AI构造的有限逻辑见证，不属于原作者完整规则`R_g`验证过的合法股票走势，也没有图像复核、市场数据或实盘回测。通过测试不意味着已解决F01或OB38。目的是明确：哪些输入前提还没有资格生成下一层结论。

## 一、为什么前一轮证明责任需要具体化？

第35课卷二p291明确讨论中枢与走势类型的相互依赖和最低级别交易序列基例；第17课卷一p197、第18课卷一p234要求三个连续的合格次级走势重叠形成高一级中枢。第67、71、78课对特征序列和合法反向线段提供更晚的细化。**源定义是递归关系，不是对任意三个高低点数组求交集便可自动证明的价格定律。**

G01必须回答：成员是否真实完成？它们是否属于同一冻结规则、相互连续？它们最早何时可确认？只有在这些前提都合法时，重叠运算才有作为父中枢候选构件的意义。最低级别中枢基例不能直接替代完整的子走势。

G05涉及的是另一个数学义务。第35课卷二p292描述连接结合律，第38课卷二p338—339讨论固定同级分解与唯一性，第33课卷二p256提出不同级别与重组多义性。**结合律只约束括号结合顺序，并不独自决定切分点的位置。** 固定规则唯一性须先明确完整输入域、候选切分的合法判定、等价关系及边界相等时的选择规则；没有这些东西，证明既无法成立，也不能因一个简化合成例子就宣称理论被推翻。

## 二、G01：最低中枢基例不等于完整次级走势

| 情境 | 合成输入条件 | 条件性结论 |
|---|---|---|
| G01-W01 | 最低层基例已经被外部假设成立，但尚未产生完整次级走势。 | `BASE_ONLY_NOT_PARENT_CENTER` |
| G01-W02 | 三个区间有数值交集，后两段仅观察到而未认证完成。 | `OVERLAP_WITH_UNCERTIFIED_CHILDREN` |
| G01-W03 | 三段连续并在当前时点完成，且非空重叠；仅得到条件性父中枢资格。 | `CONDITIONAL_PARENT_OVERLAP_NOT_AUTHOR_CERTIFIED` |
| G01-W04 | 三段完整但共同交集为空，结构条件不满足。 | `NO_COMMON_OVERLAP` |
| G01-W05 | 第三段尚未到首次确认时点，不能以事后完成身份提前标注。 | `ASOF_CHILD_PENDING` |

特别要区分三种“完成”：**成员在未来回看是完整的**、**成员在某历史时点已可确认**、**成员满足作者全部版本规则的合法认证**。测试中的`complete=true`只是外部假设，不能被审计器当成作者已经完成了认证。G01-W03能在给定假设下做条件性交集判定，不代表完成作者理论中的全部成员资格认证；G01-W05则显示事后确认时间不能偷渡到更早的当下。

G01所需进一步材料是冻结版本下从笔和线段到合格次级走势的全部合法性条件、第67课无缺口/有缺口两种分支与第71课严格特征元素身份、第78课合法反向线段破坏条件、完成事件及首次可知时间。相关现有研究见`catalog/chanlun_f01_typed_completion_obligations_v1.json`和`catalog/chanlun_f01_segment_termination_reconciliation_v1.json`。

## 三、G05：结合律与规范唯一性是不同命题

| 情境 | 合成竞争切分条件 | 条件性结论 |
|---|---|---|
| G05-W01 | 固定相同规则并假设有两种互不等价的合格切法，仅用结合律不足以裁决。 | `CONDITIONAL_NONUNIQUENESS_IF_BOTH_LEGAL` |
| G05-W02 | 两种分法分别由不同规则产生，不能当作固定规则唯一性反例。 | `CROSS_RULE_COMPARISON_NOT_COUNTEREXAMPLE` |
| G05-W03 | 只得到一份候选切法，不证明所有输入都唯一。 | `ONE_ASSUMED_PARSE_NOT_UNIVERSAL_PROOF` |
| G05-W04 | 没有合格切法声明，存在性义务仍未满足。 | `EXISTENCE_NOT_SHOWN` |
| G05-W05 | 两个括号表达式使用相同分界点，不构成不同切法的证据。 | `SAME_CUTPOINTS_NO_COUNTEREXAMPLE` |

G05-W01中两套分界点被**外部假定**为同规则下合法：如果这两个条件真的在完整作者规则下同时成立，则构成一个唯一性障碍。但我们并未证明其作者合法性，因此不能称其为“已经找到缠论反例”。G05-W02中的第二套分解采用另一规则，不能作为同规则唯一性反例；G05-W05只改变候选的表示次数，没有出现不同分界点，因此也不能证明非唯一。

从理论证明角度，下一步至少要分别说明：
- 每个合法完成输入是否存在至少一个规范型（存在性）；
- 何谓两种切分等价（唯一性命题的等号标准）；
- 相等价格、盘整连接、延伸与新生竞争和未完成尾段如何决断；
- 完整输入上的规范唯一性是否可能在前缀`H_t`上实时确认。

## 五、下一步最有价值的工作

优先处理**G01合法次级走势认证**：为各版规则分别形成可检查的状态转换与完成时间定义，保留明确的未知状态，不将缺失证据当成未发生。其次处理**G05的规范化重写规则**：定义输入域、合法切分与同价边界的冲突裁决，才有资格讨论合流性与唯一规范型。

**本轮结论**：我们能够拒绝若干错误推论，但不能给出F01或OB38的全域证明，也没有合规地证伪整套理论。MARKET_NOT_RUN / IMAGE_NOT_RUN / PROOF_OPEN。
