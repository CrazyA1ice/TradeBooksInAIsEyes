## 2. 实质新纠错：必须区分整个回拉的极值与买点所在的完成端点

以某冻结`R, g, CENTER_ID`和合法次级回拉成员`M`为条件，定义**研究者审计字段**（作者未公布同名数据模型）：

| 对象 | 可审计意义 | 第24课是否支持等同 |
|---|---|---|
| `RETRACE_ENVELOPE_LOW` | 将某次完整多段回拉所涵盖的所有已见价格作全区间最低值 | **不支持**总拿这个最低时刻作三买结束点 |
| `TERMINAL_CHILD_LEG` / `TERMINAL_LEG_LOW` | 最后C段（或复杂五段里的最后一个回拉段）及其内部极值；成员身份须固定 | 作者给最后段关系的**必要研究线索**，但没给逐笔唯一分段函数 |
| `THIRD_BUY_ENDPOINT_PRICE_TIME` | **当事层级实际第三买点结束事件**的价格位置与历史发生时刻 | 作者**明确允许它与完整回拉的最低位置不同** |
| `CHILD_MOVEMENT_COMPLETED_KNOWN_AT` | 此次合法完整g−1回拉何时首次可证明完成 | 作者本回复**未给**跨所有低级结构的完成算法；不可由历史买点位置回填 |
| `THIRD_BUY_QUALIFIED_KNOWN_AT` | 固定R、原中心、合法离开、首次完整外回试和价格条件都可核时的信号首知 | 不等同于端点价格发生时刻，仍受F01/第38课身份门限制 |

仅在**完整回拉的观察域确实包含最后段全部价格**时，有`RETRACE_ENVELOPE_LOW <= TERMINAL_LEG_LOW`，但不能反推买点端点一定是该最后段最低价，更不能由该不等式推出买点处于ZG上下哪一侧。第24课“C段不创新低”足以证明**价格最小值的时刻与完结信号的位置可能不同**；**并未证明在指定600832案例中此前低点确实已经跌入[ZD,ZG]**，也不自动取消第20课所写“低点不跌破ZG”的文字限定。

## 3. 与v4.70价格门的接口修订：先问“哪个价格”，再判断不破界

[v4.70六行表](CHANLUN_L20_L38_BOUNDARY_TOUCH_RETRACE_ROLE_V470.md)为简化数值语义，把`L`称作“回试极值”；该模型只适用于**已证明所比较的L就是第20课相关条件在冻结分解R下所指价格对象**的情形。现在不能无条件把多段回拉的`RETRACE_ENVELOPE_LOW`传给`P20_PRICE`，也不能无条件把最后一段最低价传给它。第24课历史作者回答说明**这两个价格对象与三买实际结束价需要独立登记**。

**有来源支撑的审稿顺序**：

1. `SCOPE`：明确比较的是第20课某个合法完整g−1回试、其内部3段/5段哪一段、还是整个回拉过程；固定`f1/R/g/CENTER_ID/DEPARTURE_ID`。
2. `IDENTITY`：有无完整回试身份`COMPLETED_CHILD_MOVEMENT_ID`，内部g−2子段不能重复消耗“第一次”；返回中枢内部的候选不能机械视为一次合格外回试。
3. `ENDPOINT`：分开`RETRACE_ENVELOPE_LOW`、`TERMINAL_LEG_LOW`、`THIRD_BUY_ENDPOINT`及各自时间，不把全局最低K线误标为作者所称结束点。
4. `PRICE`：在**价格对象和作者谓词的适用域均已认证**时，再应用第20课`L>=ZG`（卖点镜像`H<=ZD`）。若`P20_PRICE_SOURCE_SCOPE=UNDETERMINED`，即使数值已知，也必须输出`SCOPE_UNKNOWN`，不靠选更好看的最低价事后挑一种分解。
5. `BOUNDARY`：若有效比较价恰好等于ZG/ZD，沿用v4.70`BORDER_TOUCH_UNRESOLVED`：**数值不破界**和**第38课回中枢里的端点语义**仍是两个问题。
6. `KNOWN_AT`：端点历史发生、目标回试第一次合法结束、中枢身份与信号认证首知分别记录；不可后验倒填首次可知。

**与v4.70具体关系**：本轮不是发现第20课等号新公式。v4.70的`L>ZG/L=ZG/L<ZG`和卖点镜像六种**纯数值关系仍成立**；本轮收紧的是“哪个价格可作为L”的**输入资格**，避免用全局极值与信号完成端点混为一谈。更不能宣称作者说“仅看最后一次回拉”就废除合法次级走势类型必须完成、原中心合法与第一次资格等条件。

## 4. 与第38课、凯翔A026及第100课C3的实际研究意义

- **第38课**：2007-03-21署时答复告诉我们，两次g−2内部回拉可能只是**同一个g−1完整回拉**；第24课2007-01-18署时答复又告诉我们，**同一复杂回拉的历史最低时刻不必是三买的结束事件**。这属于**两个独立的层级错误**：把内部拐头过度计数，以及把全区间最极端价格直接当信号端点。
- **凯翔A026**：当下候选排除不能靠事后把“回拉最低价”调整为“最后一次回拉结束价”而使原先被否的买点重新成立；必须说明固定R与价格对象为什么是作者所指，拿不准则保留`PRICE_OBJECT_UNKNOWN`。
- **第100课5分钟三卖C3**：本轮新作者回复**直接讨论三买及回拉低点**。若用于三卖“最高点和结束时刻”应明确标`BUY_TO_SELL_SYMMETRY_RESEARCH_INFERENCE`，不可以冒充第24课当晚作者直接讲过三卖的独立证据。第20课正文明确有三卖镜像公式；是否所有复杂回抽的高点都能按此对称替换，仍要核原文和结构完成证书。
