# 《缠论》G01/G05：有类型的条件规则与规范化前提

> **方法定位**：这是基于既有作者SOURCE卡的**AI限定规则契约**，并非作者已经发表的完整可执行算法。12组测试使用人造、外部声明的条件数据，不读取股票行情、不重新核全部原PDF图示，不证明F01或OB38。该研究接续[上一步10组条件见证](G01_G05_CONDITIONAL_WITNESS_STUDY.md)，改为显式状态转换及规范化前提。

## 一、G01：不要将局部分型直接提升为完整次级走势

作者第67课区分有缺口和无缺口的特征序列情形，第71课强调严格特征成员与待定笔的身份，第78课要求破坏由合法反向线段完成。其要求处在**不同的类型层级**：观察到局部特征形态 ≠ 已有合格反向线段 ≠ 一段完整的低级别盘整或趋势。尤其第18课还说明达到最低结构资格不等于走势已经终止。

当前契约只使用以下状态，不产生作者级别的完成证书：

- `INVALID_FEATURE_SCOPE`
- `PENDING_LOCAL_PATTERN`
- `PENDING_GAP_OPPOSITE_FRACTAL`
- `LOCAL_PATTERN_ONLY`
- `PENDING_LEGAL_REVERSE_SEGMENT`
- `EXTERNAL_REVERSE_SEGMENT_ASSUMED_NOT_FINISHED_LOWER_TYPE`

规则顺序是：先核实严格特征成员，再审第67课局部条件；有缺口时检查反向分型是否**在as-of时点之前**完成；之后才考虑外部声明的反向合法线段。如果只有外部声明，也最多进入`EXTERNAL_REVERSE_SEGMENT_ASSUMED_NOT_FINISHED_LOWER_TYPE`，不能跳到“完整次级走势已证”。这些检查是AI的保守状态门控，而非原作者所有版本的穷尽状态机。

### 六个G01定向案例

| 案例 | 情境 | 限定结论 |
|---|---|---|
| G01-T01 | 严格特征序列身份不成立，局部分型不能作为合法构件证据。 | `INVALID_FEATURE_SCOPE` |
| G01-T02 | 无缺口情景仍没有局部作者条件，状态保持未定。 | `PENDING_LOCAL_PATTERN` |
| G01-T03 | 有缺口但反向分型尚未在当前时点确认，不能提前使用未来材料。 | `PENDING_GAP_OPPOSITE_FRACTAL` |
| G01-T04 | 无缺口局部条件已经呈现，但缺独立合法反向线段证明。 | `LOCAL_PATTERN_ONLY` |
| G01-T05 | 有缺口且反向分型已被外部声明，仍须等待合法反向线段。 | `PENDING_LEGAL_REVERSE_SEGMENT` |
| G01-T06 | 合法反向线段仅以外部假设提供，不产生完整次级走势证明。 | `EXTERNAL_REVERSE_SEGMENT_ASSUMED_NOT_FINISHED_LOWER_TYPE` |

## 二、G05：把候选分解与规范化裁决明确分离

第35课所说的连接结合律并不指定一个分解的切点。第38课提固定同级别分解唯一性，但是在判断之前必须有**冻结的规则版本**、合法完整输入、分解合法性定义及等价标准；第33课的多义性与第102课进位制类比也不自动构成唯一性证明或反证。

本契约接收`candidate_cutpoints`作为**外部提供的假定候选切分**，并不替原作者验证其合法性。没有候选时保留存在性义务，只有一份候选时不宣称全域唯一，两份不同分界点同时存在时若没有平局政策则保留冲突。

只有在显式写出`LEXICOGRAPHIC_AI_ONLY`时，工具才用字典序选择一个结果；其用途是展示**程序可以确定性输出，却仍然没有作者规范型唯一性的证明**。这个政策不是从第38课原文推导出来的。

### 六个G05定向案例

| 案例 | 情境 | 限定结论 |
|---|---|---|
| G05-T01 | 输入历史尚未完成，最终切分规范型不得提前锁定。 | `WAIT_COMPLETE_INPUT` |
| G05-T02 | 即使假设连接结合律成立，没有候选分解仍缺存在性证明。 | `NO_CANDIDATE_EXISTENCE_OPEN` |
| G05-T03 | 单一假定合法分解不能推出所有输入唯一。 | `ONE_ASSUMED_PARSE_NO_UNIVERSAL_PROOF` |
| G05-T04 | 同规则存在两个外部假定的不同切分，在没有裁决政策时保持冲突。 | `MULTIPLE_ASSUMED_PARSES_UNRESOLVED` |
| G05-T05 | AI明确采用词典序平局裁决后只得到确定性程序选择，不代表作者唯一性。 | `AI_ONLY_DETERMINISTIC_SELECTION_NOT_AUTHOR_UNIQUENESS` |
| G05-T06 | 两个候选的分界点实际相同，不因重复表示产生非唯一。 | `ONE_ASSUMED_PARSE_NO_UNIVERSAL_PROOF` |

## 四、继续证明需要什么

**G01下一层任务**是把外部假设“合法反向线段”替换为经冻结作者规则验证的构件，同时建立完整次级走势、结束事件与首次可知时点的认证关系。这里缺失的证据不能被`false`含糊代替，要记录`PENDING`。

**G05下一层任务**是先明确合法分解生成器、规范型定义和切分等价关系，再分别检查存在性、终止性、临界价格平局、规范化冲突收敛性。人为指定字典序可以使玩具模型输出确定，但不能替代作者规则证明。

**总结**：本轮从抽象证明义务推进到了12组带类型、时间、规则版本与候选分解身份的可执行检查；F01和OB38仍`OPEN`。真实行情与图像均`NOT_RUN`。
