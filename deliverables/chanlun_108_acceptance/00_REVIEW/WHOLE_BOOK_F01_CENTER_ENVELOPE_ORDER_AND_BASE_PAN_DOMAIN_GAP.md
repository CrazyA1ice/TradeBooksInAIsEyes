# F01再推进：第20课已经能计算两中枢的哪些高低关系？为什么仍不能替代第35课完整趋势比较器？

> **v4.33.0｜2026-11-11**。承接[第35课最低中枢基例与完成收据](WHOLE_BOOK_F01_PROOF_CARRYING_COMPLETION_RECEIPTS_AND_BOTTOM_CASE.md)，不再从“没有比较器”笼统起步。本次交叉核对[第20课原文](https://eczsc.com/originals/20)（2007-01-05，卷一物理p.246–247，`CL020-S08`）、[第35课原文](https://eczsc.com/originals/35)（2007-03-09，卷二p.291，`CL35-SO-2/SO-9`）及第17、18、84课的递归基例。取得可直接算的**严格向上/向下分离与高级别扩展的四个数值模式**，同时用**相同中枢核心区间、不同整体极值**的成对反例，严格说明为何不能仅靠`[ZD,ZG]`恢复第20课的分类。进一步发现，第20课“完整次级走势离开/回试的第三类点”如果原封不动套到第35课以逐笔交易为绝对最低层的`f1`，会要求一个根本未定义的“下一更低级别完整走势”；所以**最低层单中心盘整还必须有独立基例或明确的额外映射**，不能在底层循环调用第20课。严格市场行情、原文最终证明与真实回测没有运行：F01/OB38/OB99=OPEN，`NOT_RUN`。

## 1. 原作者的`GG/DD`和`ZG/ZD`不是同一对数

第20课正文对一个中枢中**与中枢形成方向一致的Z走势段**列出`g_n,d_n`，并定义：

| 符号 | 第20课含义 | 不能替代为 |
|---|---|---|
| `GG = max(g_n)` | 该中枢相关Z走势段**最高高点** | 中枢核心上沿ZG |
| `DD = min(d_n)` | 该中枢相关Z走势段**最低低点** | 中枢核心下沿ZD |
| `ZG = min(g1,g2)` | 核心重叠区间的**上沿** | 整个走势的最高价 |
| `ZD = max(d1,d2)` | 核心重叠区间的**下沿** | 整个走势的最低价 |

因此在这些定义以及中枢核心确实存在的**必要数值约束**下，`DD ≤ ZD ≤ ZG ≤ GG`。从**只有这四个数且尚未核验Z段/中枢合法成员资格**的输入出发，程序最多能检查局部数值条件，不能凭四个数构造出市场中真实的合法中枢。

原仓库第20课证据卡已明确标注：卷一p.246–247有作者课文与后附“娇注”的排版混杂，不能以整理者括注代替作者自己的公式。[证据卡](../../../knowledge/evidence/chanlun_lesson020.json)及[局部数值模式机器记录](../../../catalog/chanlun_f01_l20_center_partial_order_and_base_pan_v1.json)。

## 2. 第20课其实已经给出四条严格的同级中枢位置关系

令前中枢为A，后中枢为B，两者必须是**合法同级别、且已确定组成成员**的对象；本报告不从随手输入四个数字就自动给出这种历史合法身份。

| 分类 | 原作者第20课给出的边界条件 | 本轮局部运算名称 |
|---|---|---|
| **严格向上分离** | B.`DD >` A.`GG` | `STRICT_UP_SEPARATED` |
| **严格向下分离** | B.`GG <` A.`DD` | `STRICT_DOWN_SEPARATED` |
| **核心区间上移、但整个Z段波动范围未完全分离** | B.`ZD >` A.`ZG` **且** B.`DD ≤` A.`GG` | `UPWARD_EXPANSION_PATTERN` |
| **核心区间下移、但整个Z段波动范围未完全分离** | B.`ZG <` A.`ZD` **且** B.`GG ≥` A.`DD` | `DOWNWARD_EXPANSION_PATTERN` |

[第20课原文](https://eczsc.com/originals/20)将前两条称为严格的上涨／下跌及延续，后两条与高级别中枢扩张联系。这是作者对**相邻同级别中枢**的条件式定理，不意味着相同数字无论上游输入是什么均生成同样中枢，也不意味着第35课的“较高”在**全部可能状态**中都与这里某一条公式完全等价。

尤其第35课在“最低上涨第N个中枢(N>2)不再高于上一个中枢时结束”使用的是**整体高低关系叙述**。第20课提供四类**明确可计算的关系**，但尚未提供一张全状态对应表，把第35课的“高于／等于／低于”及其结尾完成时间与全部可能的中心扩展、边界接触与解析政策严格等同。因此**第20课解决的是部分比较子问题，不是将F01完整闭环**。

## 3. 一对同核心、不同整体极值的明确反例

只用虚构区间演算（**这些数字不是航天机电历史价**），固定前中枢A：

```text
A核心：[ZD,ZG]=[10,12]    A相关Z段整体范围：[DD,GG]=[8,14]
```

比较后中枢B的两个**核心完全一样**的版本：

| 后中枢（仅用于代数验证） | B核心 | B整体范围 | 第20课局部条件 |
|---|---|---|---|
| B₁ | [16,18] | **[15,20]** | `15>14`：严格向上分离 |
| B₂ | [16,18] | **[13,20]** | `16>12`且`13≤14`：上移但整体范围交叠，属扩展模式 |

A和B的**核心区间完全相同**，只把B在Z段里的最低极值从15改成13，分类就变化了。因此以下推理是无效的：

> “`后ZD>前ZG`，所以两个中枢必然构成第20课意义的严格上涨分离。”

严谨地说：`后ZD>前ZG`只保证**两者核心区间严格分离**；还要判断整体Z段的`后DD`和`前GG`，才知道属于第20课的严格分离还是扩展模式。程序会在这两种B上输出不同标签并以此作回归检查。

另一个容易误写的边界是`B.DD=A.GG`：由于严格上涨需要`>`，**两者刚好相等时不能标为严格上涨**；若核心区间已经上移且满足`≤`，属于上行扩展模式。若两个核心区间只是端点相接，即`B.ZD=A.ZG`，第20课的上行扩展要求严格`>`，它也不自动符合该条。后者在本轮“四模式”分类中报告为`UNDETERMINED`，而不是替作者发明“等于就当扩展/趋势”。

**范围**：四条公式本身并不是对一切两中心输入的完整、无二义、可交易分类器。扩展模式中的最终新高级别中枢仍需要真实合法的次级走势作为证明；数值符合不等式仅是输入条件检查。

## 4. 为什么单中心最低盘整不能直接靠第20课第三类点结束？

上一轮找到的2007-08-21作者署时评论将盘整的结束标志说成第三类买卖点；[第20课第三类点正文](https://eczsc.com/originals/20)却有不可省略的前提：**一个完成的次级别走势离开，随后首次由一个完成的次级别走势回试/回抽**，并要求相应极值不跌破`ZG`／不升破`ZD`。[作者答疑来源和认证边界](WHOLE_BOOK_AUTHOR_REPLY_COMPLETION_EXIT_EVENTS_AND_NONCIRCULAR_PROOFS.md)。

现在把级别放到最底层：

1. 第35课为了避免循环，将**逐笔成交**定为严格定义下的绝对原子`level=0`，三笔同价交易可以定义**最小中枢存在**。
2. 若机械套用第20课的统一第三类点递归接口：“第0级第三类点”又要求`level=-1`的**完整次级走势类型**，而作为`f1`的绝对逐笔原子并没有一个作者已定义的`level=-1`。
3. 因此这套**未加基例的统一递归写法不能在第0级自行闭合**。要真正解决，需要额外给出底层盘整**特有的终结规则**，或者证明作者在此处明确采用与高层第三类点不同的基础构造与完成接口，并冻结版本。

**这是一项有类型的递归定义域缺口，不是证明单中心盘整永远不会结束，更不是证明作者的整个理论自相矛盾。**第35课给了最低级别趋势N>2时的独立方向谓词，但最低只有一个中枢时没有因此自动获得合格的结束时钟。

第84课[原文](https://eczsc.com/originals/84)允许最底层初始化函数`f1`与后续递归`f2`不同。**这恰好允许未来有一个非同构底层基例的可能性**，不能反过来利用这个许可假定“我们已经有了这个基例”。

## 5. 本轮代码真正做的事，以及必须拒绝的过度结论

新增[局部比较审计器](../../../tools/audit_chanlun_f01_l20_center_partial_order.py)和[机器对照清单](../../../catalog/chanlun_f01_l20_center_partial_order_and_base_pan_v1.json)。只处理**明确标注为虚构的两个四元组**，使用精确十进制算术校验`DD ≤ ZD ≤ ZG ≤ GG`，核对四条作者不等式及“不能从核心区间恢复整体Z段极值”这项有限反例。输入缺字段、端点顺序错、非有限价格、边界等号误写、来源作者页与整理者页混淆均应拒绝。

对应专项测试不做真实行情OHLC读取。审核输出**`PASS_LOCAL_FORMULAS_ONLY`**，严格限制到“如果A、B已经是合法同级别中枢，则这些数字符合哪一条第20课公式”，不提供第35课全定义比较器、不输出`FINISHED_MOVEMENT`完成证书，更不输出交易买卖信号。

对比v4.32的[有向无环完成收据研究](WHOLE_BOOK_F01_PROOF_CARRYING_COMPLETION_RECEIPTS_AND_BOTTOM_CASE.md)，本轮得到**真正的局部收紧**：

- 从“第35课较高比较器完全未知”，提升为“第20课对**严格分离/扩展**至少给四种源文可验的局部比较条件，能条件性计算”；
- 从“最低盘整出口还没找到”，提升为“已知上层第三点出口的**输入类型在绝对基础级别不闭合**，准确指出需新增的f1终结基例位置”；
- 明确拒绝“核心区间上移=严格上涨”、“中枢存在=走势结束”、“上层有三类点=不需要下级完成证明”、“测试数据正确=历史盘整已验真”。

## 6. 按理论实质推进的下一步

F01剩余的**两道最重要的底层关口**是：

**A. 高低的总比较器**：查作者是否在更后课、回复或源稿有把两中心的全域关系（尤其核心接触、重叠、扩展、高低相等）与第35课“不再高于”的`Nth`判据逐一明确映射；若没有，按`UNDETERMINED`保留而不允许将“不是严格分离”直接等同“趋势已结束”。

**B. 真正终止单中枢底层盘整的f1规则**：明确在原始逐笔级别（无更低一级完成走势类型可递归引用）下，是哪些**最少原子输入**使该盘整已完成，怎样保证首次可知时刻不偷看未来、怎样区别中心延伸与退出，且何时可以被第18课升级为**已完成的一个次级走势类型**。不能仅凭三笔同价出具完成证书，也不能拿第20课一个高层的第三类点无条件填入底层。
