- **首轮覆盖108课 ≠ 所有图/附注已经核完**。来源精确价位、后发表文章身份、部分附图尚有明确缺口，见[覆盖缺口优先表](../00_REVIEW/DETAIL_COVERAGE_GAPS.md)。
