## 每一条都要坚持的三个区分

- **原文说过 ≠ AI推导出 ≠ 数学或市场已经证明**。阅读时按`SOURCE`（原文/来源）、`INTERPRETATION`（AI释义）、`INFERENCE`（AI推理）、`HYPOTHESIS`（未验证问题）区分；“原文定理”只说明作者使用这个称呼。
- **示意图 ≠ 书中原始行情图**。这里的图全部是AI用于讲条件的简图，保留可编辑Mermaid源码；不复制、伪造或冒充未经确认的原图精确价位。
- **首轮覆盖108课 ≠ 所有图/附注已经核完**。来源精确价位、后发表文章身份、部分附图尚有明确缺口，见[覆盖缺口优先表](../00_REVIEW/DETAIL_COVERAGE_GAPS.md)。
