# 缠论事件实验室 v2｜不可变候选修订日志与线段特征序列必要条件

本阶段是**纯合成、只读、研究原型**，并非完整的缠论笔、线段、中枢解析器，也没有行情实证、真实投资回测或下单。

## 与v1不同的可验证新增能力

1. **逐根已完成K线回放**：直接复用v1的`ClosedBar`严格字段、`known_at`、OHLCV decimal、来源SHA、单标的/频率连续序号、固定`UP/DOWN`方向及独立的笔规则选择。跳过尚未完成/内部未可知的bar被禁止。
2. **不可变事件流水**：每次完成一个连续可知的bar前缀，重新计算**局部分型候选**及（规则确认为可用时）**笔必要条件**。按**来源中心原始K线key**（不按会移动的标准化序号）区分分型候选；笔候选身份为`左分型ID+右分型ID+笔规则版本`。输出`OPEN/REVISE/RETRACT/REOPEN`，保留所有历史，不回改原事件；修订或撤销发生在**实际观察时刻**，不是历史极值时刻。
3. **每条事件都有校验链**：`event_id`由标准化内容SHA256得到，`ordinal`、`revision`、`supersedes_event_id`、`observed_at`、`prefix_digest_sha256`和证据有效时间独立审计。可据同一事件序列重新得到最终活跃候选。
4. **线段局部必要条件**：引入第67/71课的**严格特征成员资格**，仅对显式输入且经合成实验指定的三根完整`STRICT`特征元素，检查分型、首两元素价格缺口和时序。带缺口时**不接受一个“对向分型已发生”的布尔宣称**，而必须有另一`sequence_id`、三根真实完成（本阶段为合成）、时间更晚的严格反向特征元素，并实际形成指定的反向顶/底局部分型。任何`AUXILIARY/UNDETERMINED`或跨序列包含均失败关闭。
5. **规则版本隔离**：第77课旧笔与第81课2007-09-18后发新笔只做局部必要门；来源时间不明的第62课附录规则仍不可自动启用。未绑定、证据不足、尚未可知的规则不会生成笔候选事件。更换规则会改变研究性笔候选ID，但不会改变底层市场数据前缀摘要。

## 关键概念与限度

- `candidate_extremum_completed_at`/分型中心bar可知时间与`confirmed_at`/本轮必要证据完成时间必须分开。后者**不是**对完整缠论笔/段的法定确认、不是成交时间。
- `feature_three_gate`输入须是**外部提供的合成严格特征元素**。它**不会**把v2的局部笔必要条件升级成真实完成的笔，也**不会**从行情推导正式线段序列或宣称作者-编者争议已经解决。
- 第67课“无缺口”和“有缺口须等待反向证据”与第71课“成员资格必须严格”的研究路径分开留痕。此处没有实现多时点线段综合划分、特征包含归并顺序的全部变体、中枢及逐级递归。
- SHA输入在当前阶段是**合成来源版本声明**，不是独立核验第三方行情文件的真实字节指纹。规则`proof_ref`只用于合成演示，不证明历史文献当日实际公开可得。
- `event_history`重放各个完整历史前缀以获得不改写的事件审计，优先研究正确性，不代表已经优化成常数时间或可运行实时生产交易系统。

## 用法（仓库根目录，单行）

只读无笔候选的事件实验：

`python -B tools/chanlun_incremental_events_v2.py`

切换明确证明时间的第77课旧笔必要门：

`python -B tools/chanlun_incremental_events_v2.py --rule pen_077_exposition --attested-known-at "2007-09-19T09:00:00+08:00" --proof-ref synthetic-research-availability`

第81课后发版本：

`python -B tools/chanlun_incremental_events_v2.py --rule pen_081_later_dated_post --attested-known-at "2007-09-19T09:00:00+08:00" --proof-ref synthetic-research-availability`

回归测试：

`python -B -m unittest discover -s tests -p "test_chanlun_incremental_events_v2.py" -v`

仅输出事件数量/哈希摘要，不提交大段版权原书文字、不接触用户的任何H5/Parquet市场库。
