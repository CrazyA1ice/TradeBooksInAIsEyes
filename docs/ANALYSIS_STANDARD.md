# 深度解读与AI独立评论标准（v2：读者优先、选择性深入）

> 执行顺序以[书籍研究工作流](BOOK_RESEARCH_WORKFLOW.md)为准。**分析可以做得深，但读者首先收到的是清楚、简短、可追溯的全书地图与灵感入口。**

## 交付层级与避免信息淹没

| 对象 | 默认要求 | 不该发生的事 |
|---|---|---|
| 全书读者 | 5分钟一句话与核心论证、15—20分钟主题地图 | 把108章独立总结直接拼成“快览” |
| 好奇的读者 | 15—30个左右高质量灵感切口（可随篇幅增减） | 只保留热门核心，删去例外、微型算例、边栏和附注 |
| 专题研究者 | 章节原文、图页、反证、形式化条件与竞争解释 | 用AI自创公式冒充作者数学定理 |
| 未来研究者 | 显式待验证题目，记录`NOT_RUN` | 自动生成交易策略和宣称行情收益 |

## 章节三级深度，而不是一律七重长文

- **A CORE**：定义、作者主要论证、跨章枢纽、重要修订。给出严谨深读。
- **B SPARK**：可能只在一页出现，但异常、惊喜、跨域迁移或反直觉。也可给出严谨深读，**不因章节排名低而跳过**。
- **C COVERED**：读过但暂时没有重大新增，保留忠实章节简述、1—3个细节和准确出处；不凑假说，不堆长稿。

无论深度如何，必须留页码与来源角色。只对值得展开的单元使用七重：**忠实理解、逻辑审视、数学/算法（适用时）、市场/行为机制、跨学科解释、未来验证题目、AI独立思考**。没有根据时标“不适用”“UNKNOWN”。

## 灵感细节卡最小合同

一个独立SPARK必须包含：**实际细节**（原著明确说了什么）、**出现位置**（卷+PDF物理页、章节/图注、来源SHA或源证据链接）、**值得记的原因**、**AI由此联想到的新问题**、**可靠程度与疑点**、**深入链接**。作者/编者/AI观点分层，特别标明未核图数字、后发定义、未知可知时间。

“启发性”与“事实可靠性”分开评价：可以公开一条`UNVERIFIED_SPARK`供思考，但不能称原文已证或历史实际信号。**不能强行每章固定N张卡**；有些章节无候选也需留`NONE_FOUND`覆盖标记。

## 全书完成标准

读者能不查其他文件先理解**问题—方法—结论—局限**；每章和边缘区域有来源/覆盖状态；有可自由点开的长尾灵感索引（例外、反例、巧妙类比、方法小技巧、冲突、图示）；重要主张追得到原始证据；全文未读或图形未核处有明确缺口。系统不能声称“所有灵感都被发现”，只能证明已经按照覆盖矩阵审查并记录不可读区域。

**双轨成果**：严谨证据档案（可长）＋读者友好的核心与灵感索引（短、可导航）；再附有独立声音的综合长评。逐章文档只保存在唯一规范目录，不在验收目录复制第二套。
