# Phase 1 · 《缠论》五卷 PDF 只读盘点

**当前阶段：** 首轮资料解析与结构核查；尚未完成任何理论单元的深度试读。

## 原始来源

仓库已有 `ChineseBooks/缠论/缠论_卷1.pdf` 至 `缠论_卷5.pdf`。本次不移动、更改、复制或公开附加摘录。原始资料的公开再分发权限待进一步核实。

## 此次交付

- `tools/inspect_chanlun_sources.py`：扫描五卷真实 PDF，输出字节数、SHA-256、总页数、PDF 元数据、内嵌目录数量、可提取文字页面比例、空白/稀疏页面数、带嵌入图片页面数、页内解析错误，以及目录候选。
- `tests/test_chanlun_inventory.py`：模拟五卷 PDF 测试脚本，验证可执行且只读。
- `.github/workflows/phase1-chanlun-inventory.yml`：仅对本次工作分支相关工具变更进行自动只读盘点，生成 GitHub Actions artifact。**不会自动将报告提交回仓库。**

### 边界说明

“文字超过 100 字的页面”仅为原生文本提取的粗略指示，不能证明 OCR 正确或文本质量合格；“包含内嵌图片”不必然表示 K 线图。扫描版 OCR、图像内容理解与逐章分析**尚未在此脚本中实现**。

### 后续验收

1. 从真实 GitHub Actions 日志与 JSON 报告确认五卷页数、SHA 与文字覆盖状态；
2. 结合试读材料核查真实目录及图表定位；
3. 若文字质量不足，设计自动 OCR 和低质量页复核，不将逐页人工校对转嫁给用户；
4. 从第一卷选择内容完整、可精确定位的一个思想单元，进行七重解读和证据审查；
5. 通过试读后再扩展到全卷。

若 Actions 因平台权限或环境限制无法运行，保持“未获得真实解析结果”状态，不推测 PDF 内容。
