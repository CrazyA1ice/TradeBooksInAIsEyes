# 阅读与解析流程（v1.0）

## 目标

对每份文献建立可复查的证据基础，避免「先总结、再猜出处」。应允许无须用户逐页核对 OCR 即可推进，但不掩盖识别错误。

## 输入登记

先记录唯一书籍 ID、真实文件路径、原文语言、书名/版本（仅核实后填写）、卷册、文件大小、SHA-256、授权状态和来源链接。使用 `catalog/` 登记，不推测未知作者、出版信息或页码。

## 解析流程

1. 识别 PDF 是否含原生文字；原生文字优先。
2. 分析目录、页码、标题层级、注释、插图、表格、公式和双栏排版。
3. 无法直接提取文字的页面通过 OCR 与视觉分析恢复；保留页码映射。
4. 对低质量页进行二次处理与自动交叉核验，记录解析信心和原因。
5. 将图文关联到同一思想单元，并记录图像范围；不以图片猜测精确原始行情数据。
6. 抽取定义、论证、结论、反例、修订和明确的研究问题。
7. 先完成思想单元和章节解读，再整体重构并反向校核先前解释。

## 失败与歧义策略

- 源文件读不到：标记 blocked，不自行补写内容。
- 图表模糊：保留原图位置与读图限制。
- OCR 结果矛盾：尝试再解析；仍无法确认则标 `needs_review`，关键结论暂缓。
- 文献缺页：记录完整性缺口。
- 原著含模糊概念：保留多种解释，不偷偷补成确定公式。

## 阶段完成条件

文档结构与页码映射可用；关键思想单元可追溯；无法确认的部分已列出；试读能证明解析质量足以支撑推理。解析完成不代表研究完成。
