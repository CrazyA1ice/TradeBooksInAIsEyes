# 阅读与解析协议（v2：快览与长尾细节同等重要）

> 规范总入口：[书籍AI研究工作流](BOOK_RESEARCH_WORKFLOW.md)。**读者先见全书核心，再追寻灵感细节；AI在背后完成必要的来源覆盖和审查。** 本文件规定证据读取步骤，不复制各书结果。

## 三遍阅读，不等于三轮篇幅膨胀

1. **鸟瞰**：锁定原始文件SHA、页码、目录、章节/序言/附注、末尾修订；快速形成全书一句话、3—7个核心洞见、思想地图的首版。未覆盖全书的版本必须标`PROVISIONAL_NOT_FULLY_SCANNED`，不能冒充最终总结。
2. **全范围双轨**：逐章/逐区域检查**CORE（主干论证）**和**SPARK（冷门启发）**。SPARK特意留意小算例、图例边角、脚注、读者问答、突然的比喻、前后矛盾、特别精度、例外、后附修订和作者自我质疑。没有收获时标`NONE_FOUND`，绝不为凑卡编造灵感。
3. **交叉反读**：从全书结尾、争议、异常案例倒查前面的解释；对重要概念、产生歧义的版别/日期和高价值图示做局部复核。更新速览、灵感索引、全书独立长评及对应证据，不强迫用户手工逐页校验OCR。

## 来源覆盖与异常

为目录、正文章节、图表标题、脚注/附录/边栏/问答分别记`SCANNED`、`LIMITED`、`MISSING`。原生文字优先，OCR与视觉辅助；图价模糊不猜数字。原书与编者/再版来源单独标注。即使已建立108章首轮研究，也不代表全体插图、脚注的内容和日期全部独立审过。

## 读者先看到的三个输出

- **5分钟速览**：一句话、核心理论和作者如何推导、适用条件、最重要的限制、思想地图入口。
- **可搜索的灵感细节卡**：用具体事例引发新问题，区分原书内容、AI联想与需要继续核实的地方；不是把摘录变成更长的文章。
- **一键深入原文**：对每条核心洞见/细节提供源卷物理页、原章研究、源SHA与重要不确定性。

**质量门槛**：全书各区域有覆盖状态；没有无证据来源的自信宣称；快览没有因简短丢掉关键限定条件；边缘材料被专门扫描，而非仅从目录挑章节。长度控制针对**读者输出**，不减少背后的证据严谨度。
