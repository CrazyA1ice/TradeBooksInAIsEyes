## 最近可执行的步骤

1. 盘点 `ChineseBooks/缠论/` 五卷的文件指纹、页数、真实目录、版本、重复内容与授权状态。
2. 构建 PDF 原生文本提取 / OCR / 图表定位质量报告；需要保证失败页可追溯。
3. 从第一卷选择一个内容完整的重要思想单元，制作 `SOURCE` → `INTERPRETATION` → `INFERENCE` → `HYPOTHESIS` 分离的深度试读。
4. 对试读进行证据与逻辑审查，再确定批量分析的基准。
5. 基准合格后，开展第一卷、其余各卷及跨卷研究。

**依赖关系：**文档解读可独立于行情数据推进。实证研究以后采用可信数据的只读接口，不能修改行情源库。

**验收失败策略：**对解析缺口保留 `needs_review`；不要让人工逐页 OCR 校验成为默认必经步骤；不要将未做过的实验标记为通过。
