# 缠论结构实验室 V3｜保守笔候选选择与线段特征类型隔离

> V3只接收**人工合成数据**，以V1闭合K线、来源版本与可知时间和V2不可变事件链为基础。本版本只完成**笔候选的保守选择策略**，不是完整缠论笔唯一性、线段、中枢、买卖点或盈利回测的实现。

## 为什么需要V3

V1逐对判断必要条件，V2逐根前缀追踪候选修订，但直接把所有相邻分型配对可能遇到：同类型分型中强者替换、等高等低的歧义、近距离不合格反向分型、后来更强极值使当前末笔候选变化等情况。V3在独立、可测试的**研究选择策略**中保守处理这些问题，而不把算法输出冒充已证明唯一的合法笔。

新增两份互不混淆的人工合成输入：V1旧样例主要用于检验局部必要门的拒绝状态，V3专用样例`experiments/fixtures/chanlun_pen_frontier_synthetic_v3.json`包含严格错开的顶底分型，用于核验**确实会创建保守笔候选**的正例及其版本化撤销行为；通过正例并不意味着真实市场已获验证。

## 状态选择策略（必要条件，不是全部缠论定义）

- **输入**：同一数据源/标的/周期已知的完整K线前缀；原始价格精度、来源SHA、市场可知时间均由V1/V2严格检查；包含方向固定为先验`UP`或`DOWN`。
- 分型身份绑定其**标准化中心K线对应的原始key集合、分型类型、同一数据来源版本与方向**。索引移动本身不能悄悄改变其身份，原始中心集合改变则产生新候选。
- 相邻候选**同类**且后者更极端：以更极端者更新末端锚点；若前一局部笔候选以旧锚点为终点，则必须用新锚点重新评估必要条件，旧候选撤回、新候选重新登记。弱者不替代强者。
- 同类且极值相等：`TIE_PENDING`，记录明确冲突，不用后续未来走势或任意偏好裁决。
- 相反类型：仅当已冻结的第77课或第81课笔版本的局部必要门`LOCAL_ELIGIBLE_NECESSARY_ONLY`通过，才生成`PROVISIONAL_PEN_FRONTIER`；不足独立K线、共用源K线、价格次序无效、极值来源不唯一时不得产生正式候选。
- 逐前缀保存所有`OPEN/REVISE/RETRACT/REOPEN`，记录观察时间、市场前缀SHA、规则版本、修订引用；后续输入不会修改较早时点的事件内容。
- 本选择策略**不是**作者全部笔定义的形式证明，可能存在多种合法分解；选择的前沿只是明确声明的保守**实验策略**，不能称唯一笔。

## 新的线段入口安全门

对局部笔候选可生成`feature_projection`，但必须标识`role=UNDETERMINED`、`source=provisional_pen_not_certified`、`complete_pen=false`。即使它具备有效的左右极值价格、原始来源key、证据完成时间，**仍不是第67、71课所要求的正式完成笔特征元素**。

V2中的`feature_containment`只能归并**相同序列的两个严格STRICT元素**。V3禁止将研究候选通过一个布尔开关直接改称`STRICT`：需要下一阶段独立补充真正的笔完整性证明和可信数据可知性审计，否则任何从候选笔到线段的自动化都必须保留`UNDETERMINED`。

## 验收边界

V3保留独立验证的纯合成数据与第77课旧、第81课新规则版本。测试会覆盖未来后缀隔离、同类更极端替代、相等冲突、相反类型失败再等待、时间闭合、来源SHA锁定、跨版本笔身份隔离、不能将候选升级为正式线段、V1/V2兼容性。
