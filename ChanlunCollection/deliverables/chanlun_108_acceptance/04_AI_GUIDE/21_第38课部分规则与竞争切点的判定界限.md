## 一、从作者文字得到的可执行规则——必须精确保留级别与量词

这次实际回查卷二[第38课p.338](../../../ChineseBooks/缠论/缠论_卷2.pdf#page=338)及[卷二p.339](../../../ChineseBooks/缠论/缠论_卷2.pdf#page=339)：p.338提出固定一层同级别进行分解及唯一性的作者断言；**不对称的两层政策在p.339完整出现**。因此也更正[第38课证据卡CL38-SOURCE-2](../../../knowledge/evidence/chanlun_lesson038.json)的原书页范围，由仅列p.338调整为**p.338、339**，附带逐页哈希和来源角色，并同步更新[625份规范文件的指纹清单](../00_REVIEW/FILE_MANIFEST.json)；不改原PDF，也不改变该证据卡旧ID。

| 结构化条款 | 来源与作者文字的限定含义 | 本次可判定什么？ |
|---|---|---|
| `fixed_level` | p.338：选择固定级别`g`作为分解对象。 | 只有相同输入、`g`、规则版本的候选才能相互比较。 |
| `selected_extension` | p.339：在**选定级别中不定义中枢延伸**。 | **不定义**只表示本套操作分解不使用该概念，绝不是声称现实价格不可能延伸，也不能偷换为全级别禁止。 |
| `selected_pan_pair` | p.339：选定级别**允许**盘整＋盘整连接。 | 若候选声明此种连接，不能仅凭该条款就将它排除；但“允许”不是“该候选已经满足完整规则”。 |
| `lower_extension` | p.339：选定级别以下**允许**中枢延伸。 | 下层这一项可被允许，但并不保证实际一定延伸。 |
| `lower_pan_pair` | p.339：选定级别以下**不允许**盘整＋盘整连接。 | 一个**明确自称有这种连接**的下层抽象候选，与这条政策相冲突；不代表我们已完成对真实K线的识别。 |
| `higher_level` | p.339：在该分解操作视角中不考虑选定级别以上。 | 不能用同一视角直接断言高层分解的具体切点。 |
| `uniqueness` | p.338、339：作者明确声称可由结合律证明分解唯一。 | **作者断言已定位，独立数学证明并没有因本次条款编码而完成。** |

这些条款并非完整原文逐字转录；程序通过原书卷SHA、p.338/p.339原生文字哈希、`SOURCE`证据卡页码及角色，**逐条核对对应的条款身份**。若将“选定级别不定义延伸”换成“所有层市场不可能延伸”、删除下层的禁止条款、移动原页或冒用编者注，审计即失败。*原书PDF汇编内的作者角色不等于在其他独立首发站点完成了历史发行版本认证*。

## 二、真正推进到“竞争切点”层：7个有限模型结果

审计器只接受显式标记为 `SYNTHETIC_SYMBOLS_NOT_MARKET` 的有序抽象原子。为了比较，候选显式给出输入身份、规则版本、层级、分段边界、声明的相邻连接标签、是否使用延伸概念，以及未完成尾段状态。这是**限定于已知条款的模型判断**，不从真实价格生成任何笔或中枢。

[七组可重复符号案例](../../../tests/fixtures/chanlun38_symbolic_policy_cases_v1.json)分别给出：

| 场景 | 程序结论 | 严格含义 |
|---|---|---|
| 相同输入、同一`g`、相同版本，两组切点都未违反已编码的显式条款 | **`COMPETING_CUTS_UNRESOLVED`** | 无法排除第二种标注方式；**不是缠论反例**，因为尚未证明两组均为完整理论下的合法走势 |
| 低于`g`的候选**明确声明**“盘整＋盘整” | `DECLARED_POLICY_CONFLICT` | 与第38课下级政策直接冲突；不是行情分型结论 |
| 两个切分属于不同级别 | `NOT_SAME_FROZEN_RULE_DOMAIN` | 不可当作对第38课固定同级别唯一性的竞争解 |
| 同一候选边界相同 | `SAME_CUTS_LOCAL_ONLY` | 两份相同输出不能证明所有合法候选均只有这一份 |
| 选定级别候选主动使用“中枢延伸”作为独立分类 | `UNDEFINED_POLICY` | 在此分解视角中**未定义**；不能误报“市场上绝不可能” |
| 一组候选仍含未完成尾段 | `UNFINISHED_ASOF_PENDING` | 不得声称未来完成后果已在当前确定 |
| 相同输入、不同规则版本 | `NOT_SAME_FROZEN_RULE_DOMAIN` | 后发规则或不同版定义不能混作相同`R_g` |

这里最有价值的结果不是“找到反例”，而是**找到了证明必须落到的具体裁决对象**：同一输入、同一规则、同一级别下，两套切点虽然都未违背这**几条已提取的政策**，仍需要进一步检查完整合法走势类型定义，才能判定究竟有一个、两个还是零个合法分解。程序始终输出**`PARTIAL_RULE_SCOPE_CHECK_PASS_NOT_A_THEOREM_PROOF`**，明确标注无法认证全域唯一，也未执行完整缠论解析器。

## 三、现在能明确追问原作者哪些规则？不是只问“唯一对不对”

若希望严谨验证第38课的 `OB38-UNIQUE`，目前剩下五个**更可操作的问题**，并且每一项都没有被我们凭空赋予裁决算法：

1. **走势类型合法性**：如何从底层最小单位逐层认定某一段为已完成`g`级盘整/上涨/下跌？作者在[第35课p.291—292](../../../ChineseBooks/缠论/缠论_卷2.pdf#page=291)描述递归基例及两条走势分解定理；这并非完整、无歧义的全序分段程序。
2. **竞争边界优先级**：如果存在两个不同起止时间的潜在中枢，在选定层允许盘整＋盘整时，究竟采用最早确认、最大延伸、最小段数还是其他原文明确的优先级？**不能由AI自行任选。**
3. **相等价格/包含判别**：边界极值恰好相等时，究竟算满足、合并还是待确认？不能从作者“唯一性”四字反推某个平局裁决。
4. **完成与当下可见性**：第36课的重组可包含未完成尾段，需区分截止观察时点的`PENDING`与后来形成的结构。后验唯一也不意味着当前立刻能判。
5. **规则版本/时间**：不能将第81课等后期笔定义追溯成第38课2007年3月原文的同期约定。定义版本变更后的分段应作为**另一个命题**单独研究。

因此**更精确的新进展**是：已经由原文锚点支持，至少可以排除一种**把第38课的同级许可错误套到下级别**的抽象误用；而“同级层出现不同切点时必须依据哪条规则裁决”仍未找到能够完整执行的定义。与[第20篇证明资格检查](20_同级别唯一性证明资格与来源证据闸门.md)并存：**部分规则获来源验证，不自动将17项证明义务中的任何一项改成“完成”。**

## 四、为何第99课仍独立开放？

第38课的政策即使最终能够证明固定`g`分解唯一，也只能回答“**给定走势如何唯一拆分**”，不能由此推得“**每条未来路径必然产生第一个更高级别中枢**”，更不能自动约束该中枢的位置。对第99课，`OB99-EXIST`与`OB99-LOCATION`仍必须独立证明，见[第19篇来源边界](19_第35_38_99课原文边界与证明可达性审查.md)及[机器可读台账](../../../reports/source_inventory/chanlun_38_99_proof_obligation_ledger.json)。
