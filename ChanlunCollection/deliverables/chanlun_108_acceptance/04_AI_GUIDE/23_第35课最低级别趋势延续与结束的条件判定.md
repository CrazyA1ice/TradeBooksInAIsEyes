# 第23篇｜最低级别的趋势什么时候“结束”？第35课的 N＞2、等价边界与可知时间

> 本篇不是重复中枢定义，而是把第35课**确实写出的最低级别趋势延续与结束条件**做成[有原文页指纹的规则契约](../../../catalog/chanlun_lesson035_terminal_comparison_v1.json)，由[只读判定器](../../../tools/audit_chanlun_lesson035_trend_terminal_asof.py)对[12组假设中枢序列](../../../tests/fixtures/chanlun35_terminal_asof_cases_v1.json)执行具有时间限制的判断。原书出处：**[卷二p.291](../../../ChineseBooks/缠论/缠论_卷2.pdf#page=291)**，页原生文字SHA-256由既有[审计脚本](../../../tools/inspect_chanlun_original_proof_text_readonly.py)锁定；原PDF、图像和真实行情均未改动或读取，**TEXT_FIRST_NO_IMAGE、NOT_RUN**。

## 一、原文到底确定了什么？从第 N 个中枢而不是第 N 根K线说起

[第35课证据卡](../../../knowledge/evidence/chanlun_lesson035.json)已有最低级别三笔同价基例、逐级递推的证据。本次新增**CL35-SO-9**，保留已验证p.291的卷SHA和原生页文本SHA，独立登记一项先前未单列的来源事实：

在作者讨论的**最低级别中枢序列**中，两中枢构成初始趋势的方向条件。继续沿该方向形成第N个中枢（作者特别限定**N＞2**）属于趋势的延续；**当第N个中枢不再高于第N−1个（即等于或低于）时，作者把它作为最低级别上涨结束的条件**。最低级别下跌的情形按相反方向描述。

必须同时保留三层限定：这里的对象是**中枢**，不是任意K线、笔、线段或三个价格数字；“不再高于”包含**等于**，不能仅检查跌破；且第N个中枢如何与前一中枢比较，**不能未经完整原文证明就用两个区间的任意单一代表价替代**。

| 已识别的作者条件 | 程序只在什么条件下使用 | 不足以证明的内容 |
|---|---|---|
| **初始两个中枢** | 第二个相对第一个：上涨方向要求`HIGHER`、下跌方向要求`LOWER`。这是一份外部给定、尚未证明合法的符号比较 | 两个任意区间**已经构成真实合法趋势** |
| **N＞2 趋势延续** | 从**第三个**已在观察时点确认的中枢开始，保持同方向比较 | 后继必然沿原方向发展、或交易可获利 |
| **上涨终止条件** | 第三个及后续相对前一中枢出现`EQUAL`或`LOWER` | 全市场意义上的“上涨结束”已被独立证实 |
| **下跌终止条件** | 第三个及后续相对前一中枢出现`EQUAL`或`HIGHER` | 自动给出第38课分段的唯一终点或买点 |
| **关系未知** | 输出`CENTER_RELATIVE_HEIGHT_UNRESOLVED` | 凭AI自己想象“高于”比较公式 |
| **还未确认的第N个中枢** | 输出`PENDING_CENTER_CONFIRMATION` | 把后知的结构提前算作当时可以看见 |

来源角色是“本仓库汇编PDF中标记的作者主文”，**没有拿汇编文件等同独立首发认证**。证据卡、卷SHA和页文本SHA必须相互匹配；一旦把这项来源错改为编者注或删除相等条件，测试和CI会拒绝。

## 二、这里新增了真正的判定流程：先观察、后确认、再看方向

[程序](../../../tools/audit_chanlun_lesson035_trend_terminal_asof.py)接受**严格标记为纯符号的假设中枢**。每条包含第几中枢、相对前一中枢的方向关系、规则版本、模拟“已观察”时刻和“已确认”时刻。它只能在`confirmed_at <= as_of`时使用关系判定；后来的中枢即使已经包含在整套合成用例中，也不能成为较早时点已经确定的证据。这条因果时间限制是**AI自设的审计约束**，不冒称作者已经在2007年给出完整实盘事件时钟算法。

比较动作按顺序执行：

1. 必须能看到**至少两个**已确认的假设中枢，第二个必须沿所宣称的趋势方向；否则连初始趋势条件都未齐。
2. 从**第三个**已确认中枢起逐一查看相对关系。上行保持`HIGHER`、下行保持`LOWER`，均只能得到“符号关系继续符合方向”。
3. 若遇到**等于**或相反方向，记录**最早一个**触发条件的中枢编号，输出`AUTHOR_TERMINAL_COMPARISON_TRIGGER_ONLY`，**不写“真实走势完成”**。
4. 任一关键中枢尚未确认、相对关系未知、版本不一致时，分别输出`PENDING_CENTER_CONFIRMATION`、`CENTER_RELATIVE_HEIGHT_UNRESOLVED`、`RULE_VERSION_MISMATCH`。不能退化成一个静态、可任意重绘的信号。
5. 即使得到终止条件，输出永远带有`legally_completed=false`；本项目尚无能够独立证明这些抽象中枢具备原作者全部合法结构条件的链条。

这能定位一个先前容易忽略的逻辑错误：**“第2个中枢与第1个相等”不是“趋势到了N＞2且终止”**。作者是在谈已经有趋势基础的情况下，后续第N个中枢不再单调的结束条件，不能把初始化失败误算成合法趋势结束。

## 三、实际验收覆盖的12组纯符号场景

[12组可复现用例](../../../tests/fixtures/chanlun35_terminal_asof_cases_v1.json)分别覆盖：上涨保持更高、上涨第3个相等、上涨第3个更低、下跌继续更低、下跌第3个相等、下跌第3个更高、相对关系未知、第二中枢与初始趋势不符、第3中枢在观察时点尚未确认、后续第4中枢不能提前泄漏、只观察到一个中枢，以及**最早终止条件不因后续重新单调而被覆盖**。

其中，“等于”是关键的新内容：上涨`HIGHER→EQUAL`及下跌`LOWER→EQUAL`都能触发作者书写的条件，但并不会因此产生“买入、卖出、盈利”或“实时已验证完成”等结论。

为了防止数据偷换，**本轮不计算任何价格区间的“高于／低于”关系**。这是有意的：第35课已核文字没有在这里提供一套足以确认全部中枢区间关系的统一算法，不能擅自挑选中枢上下沿、区间均值或中心点作为作者唯一标准。程序要解决的是**在已有合格中心序列与相对关系被独立验证后的条件逻辑**，还不是底层全量事实检测。

## 四、实际消除了哪些误用？哪些前提仍然没有补齐？

这次的前进是：已把最低级别趋势结束的**第三中心门槛、相等边界、反向关系、时间确认与首个触发事件**变成可回归的明确条件，能排除好几种错误推导。与[第22篇条件递归中枢](22_第17与35课递归中枢条件的来源可核判断.md)一样，它不是完整缠论解析器，也**不能把条件触发者直接作为已认证的次级别走势输入**。

[规则契约](../../../catalog/chanlun_lesson035_terminal_comparison_v1.json)仍保留**五项**不允许伪造的外部来源前提：真实合法的最低级别中枢、原文高低比较的精确定义、真实中枢确认时间、连续且不被任意重叠的中枢成员、单一已冻结的历史版本。全部未验证前，本工具只输出`CONDITIONAL_TREND_COMPARISON_ONLY_NOT_COMPLETED_TREND`，不会升级为合法走势证书。

特别是：

- 对第38课 **OB38-EXIST／OB38-UNIQUE**：最低级别一条终止比较条件是递归过程中必要的局部规则，**不等于**构造了全级别唯一分段。
- 对第38课 **OB38-ASOF**：模拟观察时点可以检查“不得看到未来确认的中枢”，但真实原始数据何时可知仍无独立证明。
- 对第99课 **OB99-EXIST／OB99-LOCATION**：某个局部最低级别趋势结束不蕴含**所有未来路径**必定形成规定位置的高级别中枢。
