## 使用前先冻结的最小试验协议

一个真正有市场意义、可复算且可否证的策略实验，必须事前写清：

- **信息集** `I_t`：每个K线、行业成员、指标、文献规则版本及来源更正何时真正可见；不得混用历史极值时间和信号确认时间。
- **条件/算法** `S_t=f(I_≤t; θ,v)`：包含方向、价格精度、规则版本、阈值`θ`、中枢与笔等结构是否拥有合法完整定义；没有必须返回`UNKNOWN`，不可直接产生正式交易信号。
- **失败事件和反事实基线**：预注册无信号、简单持有、同风险预算或不同规则版本的对照组；禁止结果出来后才换基线。
- **观察区间与样本范围**：交易频率、预测期限`h`、建模/验证划分、动态股票池、停牌/退市与幸存者偏差；使用可核实的来源版本。
- **实际执行**：买卖时间、T+1、涨跌停/停牌、交易队列、成本、滑点、资金约束与不可成交次数。
- **效应量与统计检验**：收益、回撤、置信区间、错误率、重绘率、时间延迟或文献一致性，按命题指定，且对多重检验做校正。
- **负例/退出规则**：什么观察会证伪原命题？日期未知/编辑争议/价格规则不唯一时如何保守记录为未决？

特别强调：从书中**回溯识别的最低点**不能当作真实买入价；某根月线尚未收盘时不能把月末确认信号写回月中；后来的行情更正不会让原历史价格在更早时间“已经可知”。
