# 《缠论》G01/G05：从外部假设走向局部证据资格核验

> 本轮在前一版G01/G05带类型契约之上，建立**证据来源和完成时点门槛**。使用已有作者SOURCE主张与11组有限合成输入；不引入原PDF图证、不使用股票行情、不声称已实现第67/71/78课的完整合法反向线段构造，亦不声称已实现第38课唯一规范分解。F01/OB38继续开放。

## 一、G01最容易被忽略的不是价格，而是“构件身份”

第71课的严格特征序列元素不得与辅助元素或另一个序列的元素混作同一合法成员；第67课的局部特征条件与第78课的合法反向线段破坏条件属于不同层次。只看到三组高低区间构成局部几何形态，还不能得出“旧线段已被合法破坏”，更不能得出“更高级别所需的完整低级别走势已完成”。

本轮执行器逐项核对：元素是否来自同一序列、是否为严格成员、每一项是否在所考察的as-of时点已经确认、外部反向线段声明有没有可记录的构件资料。即使具备局部反向证据，也输出`LOCAL_REVERSE_EVIDENCE_NOT_AUTHOR_CERTIFIED`，不颁发作者完整合法证书。

| 情境 | 需要特别区分 | 结果 |
|---|---|---|
| G01-E01 | 三个同序严格成员，但未提供反向线段结构证据。 | `PENDING_REVERSE_SEGMENT_EVIDENCE` |
| G01-E02 | 辅助元素不可假冒同一严格序列第三成员。 | `INVALID_STRICT_SEQUENCE` |
| G01-E03 | 未来才确认的严格成员在当下不可使用。 | `FEATURE_NOT_YET_ASOF` |
| G01-E04 | 混用不同特征序列的成员不能组成完整同序证据。 | `INVALID_STRICT_SEQUENCE` |
| G01-E05 | 外部声明的反向线段若没有分层构件仍不能认证合法。 | `EXTERNAL_REVERSE_UNVERIFIED` |
| G01-E06 | 反向构件有局部来源但缺完整语法认证，仍保持局部条件。 | `LOCAL_REVERSE_EVIDENCE_NOT_AUTHOR_CERTIFIED` |

这里仍然没有对第67课“无缺口/有缺口”构成法做完备的作者原文算法：`construction_evidence`中的字符串只表示**外部提供了哪类线索**，不是我们已经根据原始市场数据独立认证它们合法。缺少完整规则和图像时应维持待定状态，而不是用假阴性代替缺失证据。

## 二、G05要解决“切分资格”而不是强行选一个结果

第35课连接结合律讨论合法连接的组合方式，但不能直接生成第38课同级规范唯一分解。第33课说明多义性与观察级别/规则有关，第102课以进位制类比规范分解，同样不构成完整合流证明。

本轮给候选切分新增来源角色：`EXTERNAL_ASSUMPTION`与`AI_CONVENTION`必须明确区分，并记录输入是否完成。不同候选若只存在于AI人为规则下，就不是原作者规范的合法候选证据；相同切点的重复不构成非唯一；两个外部假定的不同切点要求保留冲突，不能直接宣布找到符合原作者全部规则的反例。

| 情境 | 需要特别区分 | 结果 |
|---|---|---|
| G05-E01 | 同一冻结规则下两个完整但相异的候选切分，需要作者规则冲突裁决。 | `COMPETING_CUTPOINTS_RULE_UNPROVEN` |
| G05-E02 | 切分仅来自AI规则，不能作为第38课合法分解的证据。 | `AI_ONLY_PARSE_NOT_AUTHOR_ELIGIBLE` |
| G05-E03 | 一个候选未完结，不能用已完成切分替代其完整性认定。 | `INCOMPLETE_CANDIDATE_PENDING` |
| G05-E04 | 相同切点的两个外部候选属于同一几何切分，不证明全域唯一。 | `SAME_CUTPOINTS_NOT_UNIVERSAL_UNIQUENESS` |
| G05-E05 | 人为优先次序选定候选，只能标为AI规范化政策。 | `AI_SELECTION_NOT_AUTHOR_CONFLUENCE` |

其中字典序裁决仅为AI程序中显式引入的确定性选择。它将多个假设候选压成一个输出，不等于证明作者固定同级规则存在唯一规范型。

## 四、与前一步相比，实际解决了什么？

前一步外部声明`strict_feature_membership=true`就可能进入后续步骤；现在必须看三个输入元素各自的序列、角色、确认时点，并对混合身份做拒绝判断。G05则从“任意提供的候选列表”推进到“每份候选必须说明来源身份和完成状态”。这是实际增强的**输入资格门槛**，而非新的全域定理。
