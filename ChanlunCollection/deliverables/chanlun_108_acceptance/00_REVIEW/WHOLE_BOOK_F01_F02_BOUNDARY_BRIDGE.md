## 一、原书究竟说了什么：把六条原文证据放回同一条条件链

**A｜中枢的生成要先有合法构件**。第18课[卷一PDF p.234](../../../ChineseBooks/缠论/缠论_卷1.pdf#page=234)，作者原文证据`CL018-S01`，定义某级别中枢来自至少**三个连续、已完成的次级别走势类型**价格区间的重叠。设已完成子走势`A,B,C`的区间为`[a_l,a_h]`、`[b_l,b_h]`、`[c_l,c_h]`，可计算的条件是`max(a_l,b_l,c_l)≤min(a_h,b_h,c_h)`。只有当`A,B,C`的**级别、合法成员资格、连续性与完成时点**已独立确证时，区间交集才有资格成为作者定义中的上级中心，而不是只成为“一组有重叠的数字”。

**B｜构成之后，走势“可以完成”不等于“已经完成”**。第18课[卷一p.235](../../../ChineseBooks/缠论/缠论_卷1.pdf#page=235)，`CL018-S07`，明确说明：盘整已经出现一个中枢后可随时完成，但也可继续围绕它延伸；趋势已有两个依次同向中枢后可完成，也可继续形成更多中枢。这一处直接阻止`center_exists ⇒ parent_trajectory_finished_now`。更严谨地说，**构成足以允许某类走势具备结束的结构门槛，但不能仅凭达到门槛给出实际终结的时钟**。

**C｜中枢的维持涉及离开与返回的走势“级别”，不是纯区间算术**。第18课[卷一p.236—237](../../../ChineseBooks/缠论/缠论_卷1.pdf#page=236)，来源卡`CL018-S03`，论述同级中枢的维持和破坏，尤其对“离开与返回是什么级别的走势类型”提出限制，并谈离开后回抽不重新返回原中枢。**注意：第18课p.236原生文字可核，而p.237与后附材料交界的来源归属仍须按段落区分**。这套论述至少要求合法的离开走势、合法的返回/回试走势、二者完成状态和原中心身份；一个单独的`high`或`low`变量没有这些身份。

**D｜作者第20课将延伸计算与新生/扩张分开**。第20课[卷一p.245—246](../../../ChineseBooks/缠论/缠论_卷1.pdf#page=245)，`CL020-S02`，对原中心中按方向取出的合法`Z_n`走势段设`[d_n,g_n]`，并冻结`ZD=max(d1,d2)`与`ZG=min(g1,g2)`。后续**合格**的`Z_n`与原中心核心重叠，是该作者中心延伸定理的数值表达；出现合格`d_n>ZG`或`g_n<ZD`时，这个全体重叠条件不再成立。可是在同一课中，作者**没有把一次越界无条件等同为“独立的新同级中枢已完结”**：还要区分形成新中心、趋势延续与高级别扩张。原卷这几页穿插“娇注”，不能将后附分类词汇误认为同期原作者证明。

**E｜第三类点有自己的明确“非跌破/非升破”价格边界**。第20课[卷一p.247](../../../ChineseBooks/缠论/缠论_卷1.pdf#page=247)，`CL020-S03`：一个**次级别走势类型向上离开**中枢，随后以一个次级别走势类型**回试**，其低点**不跌破**`ZG`，则构成第三类买点；向下离开并回抽，高点**不升破**`ZD`，则构成第三类卖点。若只抽出这句里可以计算的价格谓词：
- **三买非跌破**：`L_retest ≥ ZG`；三买严格远离：`L_retest > ZG`。
- **三卖非升破**：`H_retest ≤ ZD`；三卖严格远离：`H_retest < ZD`。

两组中的**等号**由作者“没有跌破／没有升破”自然保留。不能悄悄改为严格大于或小于。**但是**这些式子只是一整套第三类点条件中的价格部件；不能因为数值成立就认为“回抽一定是首次、走势类型已经完成、原中心确实合法存在、必定可盈利”。这里的“首次回试”、回试走势完成及其观察时点，仍须逐项对照来源与第18课，不应被一个后验价格低点代替。

**F｜第35课提供最低级别基例，却没有给所有高一级状态颁发完成证书**。第35课[卷二p.291](../../../ChineseBooks/缠论/缠论_卷2.pdf#page=291)，`CL35-SO-2`的原文意思是最低级别逐笔成交模型中三笔连续同价**构成**最低级别中枢。此前已厘清这是真正的条件性定义基例，不能弱化成“仅是中枢必要条件”。但“出现一个最低级别中枢”与“这个最低级别盘整已经结束”，以及“它已经是某个高一级中枢所需的已完成次级走势”，仍是不同谓词。**从严格基例到更高级别递归缺少的是合法构件分割和终结确认，不是缺少第三笔相同价格。**

这六条文本条件共同构成**可追溯的条件链**：`(原始成交/合法构件) → (中枢存在) → (中枢维持或离开) → (次级别合法首次回试) → (价格边界测试) → (结构终结与独立新中枢另行确认)`。箭头是**研究者的条件依赖/阅读流程**；其最后两步不能仅由前面几项算术条件无前提推出。

## 二、真正发现的边界张力：一点接触对第三类点和对“严格不返回”不是同一回事

设作者已定义且合法存在的原中枢核心`Z=[2,5]`，并仅假定有一段**合成、外部声明**的向上离开后的回试`R=[5,8]`。在这里，`L_retest=5=ZG`。

对第20课明确的**第三买低点“不跌破ZG”价格部件**，`5≥5`为真。若有人把第18课的“回抽不回到原中枢”先解释为**闭区间完全不相交**，则`R∩Z={5}`，所以**严格不交**为假。两者真值确实不同。

这说明：
1. `LOW_NOT_BELOW_UPPER_BOUNDARY`与`CLOSED_INTERVAL_STRICTLY_DISJOINT`不是同一个数学谓词。
2. **如果**研究者不加限定地写“第三类点价格条件成立 ⇔ 原中枢遭到严格不接触式破坏”，这个双向等价式就被`L=ZG`的数值例子反驳。
3. 但是**不能**凭这个抽象数字例子宣布原作者第18课与第20课相互矛盾：原文“回到中枢”的语义可能区分实体区间与边界、次级走势级别和完整结构身份；若要说作者两课冲突，必须先证明它们在**同级别、同一合法走势、同一版本、同一边界包含策略**下提出了相反命题。现有文字不足以完成这一证明。

向下情形完全对称：中心`[2,5]`，向下离开后的回抽区间`[0,2]`具有`H_retest=2=ZD`。第20课“**不升破ZD**”数值成立，闭区间与原中心仍在`2`处触及；同样不能直接宣布回抽从未触及中枢。

将回试改为向上`[6,8]`、向下`[0,1]`，则**非跌破/非升破**与**严格不接触**两种数值条件同时成立。但是这仍然**没有证明**：
- 离开和首次回试两段是否为完整合法次级别走势；
- 所述中枢及其`ZG,ZD`是否来自合法的三个已完成次级构件；
- 原中心是否在回试前已被同级别新中枢或高级别扩张改变归属；
- 价格区间是否由当时已经观察到的完整走势产生；
- 三买/三卖作为实际作者定义的完成事件在哪一时点才能确认。

由此得到本轮**新的、确切但有限**的数学结论：`L≥ZG`不能推出`L>ZG`，`H≤ZD`不能推出`H<ZD`，故二者各自的触碰边界必须单列；`L>ZG`也不能直接推出“完整结构破坏”，因为它没有成员合法性的前提。

## 三、时间维度：为什么已经在图上看到的回试低点，不等于当时已经能够知道？

设一个人工声明的合成回试在`09:30`开始、`09:32`才宣称结束。如果研究者站在`09:31`，从完整回试的最终区间`[5,8]`读取`L=5`就是使用未来时刻的资料。**即使最后非跌破条件成立，也不能把09:32才知道的低点提前填进09:31的输出**。

本轮[条件审计器](../../../tools/audit_chanlun_f01_f02_third_point_boundary.py)对尚未到达`confirmed_at`的假设次级走势返回`PENDING_CHILD_COMPLETION_ASOF`；包括`third_point_weak_price_condition`在内的价格比较结果均为`null`，不泄漏未来完整段的高低点。这个`confirmed_at`是**模型中的外部合成声明**，并非作者为真实市场中每个走势段规定了统一的时钟。对真实行情若没有合法结束条件与时间证书，就不能把它设成事实。

如果某一回试被**人工声明为第二次而非首次**，即使`L=ZG`，该审计器也返回`NOT_FIRST_RETEST_DECLARED`，不把它提升为第三类点。这是为“首次身份”保留的必要资格关口，但**“我声明它是第一次”本身仍不能作为来源认证**。任何一次完整回试即使同时通过弱、严格两套数值条件，仍只得到数值结论，不能自动获得`author_third_point_certified`。

这一步改进的是**研究中的前视约束和证明层次**：过去一个假设价格区间可以让人看到未来；现在连计算测试也必须保留时点与外部合法性限定。对后面的第38课`OB38-ASOF`、第99课`OB99-EXIST`，这也是不可删除的前提。

## 四、三种完成状态必须分别记账：中枢、走势类型、第三点不是同一个完成事件

可以用三列独立的研究状态来理解：

| 事件/判断 | 需要已经有的证据 | 没有证据时能保留什么 |
|---|---|---|
| **该级别中枢已构成** | 三个连续合格已完成次级走势的区间交集；最低逐笔层另有第35课基例 | 仅`SOURCE_CONDITIONAL_CENTER_EXISTENCE`或`CENTER_MEMBERSHIP_OPEN` |
| **同一级别盘整/趋势已结束** | 合法中枢身份、走势类型成员、作者认可的结束/重组条件及观察时钟 | `TYPE_MAY_FINISH_BUT_NOT_CERTIFIED_FINISHED` |
| **第三类点数值条件成立** | 一个已经确定的`ZG/ZD`与回试完整`L/H`，另有明确方向 | `NUMERIC_WEAK_THRESHOLD_ONLY`，不能直接升级为真实第三类点 |
| **原中枢已被真正破坏** | 次级离开—回抽结构的完成和归属、返回边界语义、该中心同级别身份 | `CENTER_BREAK_SEMANTICS_OPEN` |
| **新的独立同级别中枢已成立** | **另外**三个合法完成的次级走势、连续性与波动重叠优先级/高级别扩张判断 | `NEW_CENTER_IDENTITY_OPEN` |
| **下一层递归有效** | 合法上一级中心所依赖的**已完成子走势类型**，而不只是三个最低中心价格 | `HIGHER_RECURSION_ELIGIBILITY_OPEN` |

过去的研究中已经做过了最低级别三个同价成交、假设`Z_n`核心重叠判定、向上/向下数值比较。这些**局部结果仍然有效**；但它们彼此之间并不存在自动填满的“完整走势已完成证书”。特别是第35课的最低中枢**可以构成**，但在更高一级别看来是否有三个**完整走势类型**，仍是全书F01最难的缺口。

## 五、本轮将来的研究问题缩窄到了哪里？

**F01没有被宣布解决**。下一次应系统阅读和对照第17、18、35、38、62—84课关于“次级走势类型完成”的作者文字，寻找**不依赖未来总体切分、不混用新旧笔规则**的充分条件或明确裁决为部分未规定。必须把历史当时可知性与事后完美分解区分开。

**F02有真实增量，但仍为OPEN**。已把“数值非破界”“严格不返回”“完整首次回试”“新中心构成/升级”“盘整/趋势终止”分成不同义词，给出**边界一点接触**的逻辑分离和因果时钟模型。下轮应该继续查第18/20课关于“中心破坏”的充分必要前提，尤其是闭区间边界接触和`Z_n`成员身份之间的关系；若无法从确凿主文判定，就保留`SOURCE_SEMANTICS_OPEN`，不能借编者娇注直接填空。

从长线看，解决F01/F02是第38课合法唯一分割证明的前置步骤；若上一级“子走势已完成”的认定本身是后验不唯一的，那么“每个实际价格前缀都能无前视唯一解析”的全称命题并未获得充分前提。因此**本轮做的是理论依赖链的一块真实接口，而不是重复试验已经会算的区间交集**。

**最终结论**：当作者说“构成中枢”“第三类买点低点不跌破”“中枢被离开/回抽破坏”时，我们必须承认这些语句含有**不同对象、不同边界和不同时间证据**。他们在原作者完整语法下是否等价、条件性相容或仍有未解决冲突，不能靠一个数值例子证明，也不能靠一个“已经完成”标签宣布。到本轮为止，**我们能够安全讲清各个已确认的条件及不能推出的结论；完整的F01/F02仍待真正源规则证明**。`TEXT_FIRST`；`ORIGINAL_FIGURES_NOT_REAUDITED`；`NOT_RUN`。
