## 1. 原始定义可以形式化到哪里？

该课将上涨、下跌与盘整同“最近一个高点和低点”相对前一个高低点的位置联系起来。令：

```text
dH = H_current − H_previous
dL = L_current − L_previous

dH > 0 and dL > 0  => 上涨（早期）
dH < 0 and dL < 0  => 下跌（早期）
dH > 0 and dL < 0  => 盘整（早期，扩张）
dH < 0 and dL > 0  => 盘整（早期，收敛）
```

当 dH=0 或 dL=0，文字没有指明归属。这不是说整个作品都无法处理相等高低点；这里只证明**本课这段字面定义本身不足以完成严格四象限外加边界的全部分类**。

测试脚本保留 `underdetermined_equal_extremum`，明确不把它臆造为上涨、下跌或盘整。采用“允许相等”或“价格容忍 ε”的变体，都属于后来研究者必须公开声明的**补充约定**。

## 2. 更严重的问题是：何时知道一个高低点已经成立？

如果极值需要右侧 k 根未来 K 线确认，那么：

```text
t_occurrence = 极值形成时的 K 线
t_confirm   = t_occurrence + k
t_trade     ≥ t_confirm 后最早允许且实际可成交的时刻
```

**绝对不能**在 t_occurrence 的价格上执行一条依赖 t_confirm 才知道的买入规则。

例如价格序列 `[10, 12, 9, 14, 8]`：若要判定索引 3 是前后各 1 根 K 线的局部高点，至少必须看到索引 4 的收盘价。这并不保证从该例可以盈利，只说明图上标注点与可交易时刻不同。

## 3. 对“背驰”力度面积的谨慎理解

作者在 p.145 提出比较前后两个同向趋势中两条均线之间的面积，以辨别力度衰减；再给出平均力度的即时思路。

实现之前必须补齐：

- 每次“吻”的开始、结束与确认是否有精确阈值；
- 面积取绝对值、有符号积分还是按方向归一化；
- 间隔内是否含等于零的样本，价格用何种复权方式；
- 对比的两个趋势段为何属于**同向**且同一时间级别；
- 什么时候能够首次知道完整面积，何时可采取交易行动。

若只看历史图形，再凭未来数据找两个“最漂亮”的面积段作比较，可能会出现识别上的后视偏差。
