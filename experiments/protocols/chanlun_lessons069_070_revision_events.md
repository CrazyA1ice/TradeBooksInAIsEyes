# 第69–70课：不可变事件流表示可修订的月线分型和中枢状态

来源：第四卷p.27–29、p.52–53；原始PDF SHA-256 `ceca9ac8b7fb13106d2085253679acf1474373fb61ca38b487d8ca01cf0ad66d`。

第69课原作者承认未完成月线笔和分型可修订，已经完成的图形不可被无限重写；第70课允许对尚未成熟的新5分钟中枢采用暂定分解。两者要求保留来源版本及首次可知时刻，而不是以后出现更完整图形就覆盖旧记录。

合成状态机以只追加形式记录`PENDING → CONFIRMED`、`PENDING → REVISED`（旧候选作废，新候选为PENDING）、或`PENDING → INVALIDATED`。已经CONFIRMED的同一个候选不能改写。所有事件必须有严格递增的时间戳。

另一个单独的中枢分支模拟器仅在明确事件出现时从PENDING进入`THIRD_BUY_UP`、`THIRD_SELL_DOWN`或`EXTENSION`之一。事件参数是外部已确认结构事实，不从真实行情自动推导。这里的互斥仅针对某一时间点的单次状态转移，而**不是断言市场整个未来永久属于一个互斥类别**。
