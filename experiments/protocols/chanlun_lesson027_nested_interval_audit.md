# 第 27 课跨级别背驰段：有限区间套与确认时间的边界审计

> 第二卷 PDF p.91–93；SHA-256 `af49aecbd363286baacbea02d3778b436df4dad797523ce0eb83846118827a66`。原著以区间套寻找历史性底部作类比；这里审查的是**有限个已知闭区间**的数学属性，而非用真实走势证明底部可提前买到。

## 一、数学上必须先成立的包含关系

设不同级别候选转折区间为 `I0=[a0,b0]`, `I1=[a1,b1]` 等：

```text
a0 ≤ a1 ≤ a2 ≤ ...
b0 ≥ b1 ≥ b2 ≥ ...
ai ≤ bi
```

这样才能认为这些区间逐级嵌套，最终候选范围为最内层区间。若某一级新候选区间没有落进原区间，则必须**明确报告不满足嵌套条件**，不能看完未来的最低点再重新定义前一层。

有限层级套叠不会自动收缩为一点：例如 [0,10] ⊇ [2,8] ⊇ [3,7]，最后仍然宽达 4。现实 K 线级别有限，第 27 课原文自己也承认无法使用无限层级保证数学上的唯一一点。

## 二、区间的两个不同时间

若转折低点实际发生在 t0，但需要到 t1 才能依走势完成规则确认，那么：

```text
occurrence_time = t0
confirmation_time = t1 ≥ t0
earliest_trade_time ≥ t1
```

**不能把确认时间偷换成发生时间。** 在历史图上定位 t0、甚至从多个时间级别解释 t0，不等于当时投资者能以 t0 的最低价完成订单。

## 三、合成反例

- 合法嵌套：[0,10] → [2,8] → [3,7]，结果非空但不是唯一点。
- 非法嵌套：[0,10] → [8,12]，新区间越出父区间。
- 未来泄漏：区间在时间 5 才能确认，却标称交易时刻 4 已知。

配套的 [Python 边界检查](../../tools/audit_chanlun_lesson027_nested_intervals.py) 会拒绝不合法输入和未来泄漏。**这些不是由 A 股价格计算得到的背驰段，不能充当原著方法实盘成败的证据。**

## 四、真正的后续市场实验

先独立定义不同级别的已完成走势及背驰段、再在每一时刻使用真实已可得的历史数据生成各层候选，记录区间不嵌套比例、未分类比例及确认滞后。只有通过上述审计，才能比较相对于简单止跌/动量基准的成本后收益。
