# MACD 当前面积乘二：部分观测能否确定最终面积？

> 《教你炒股票24》，第二卷 PDF p.3–4。源 SHA-256 `af49aecbd363286baacbea02d3778b436df4dad797523ce0eb83846118827a66`。

作者提出通过比较趋势 A/C 段的 MACD 柱面积辅助判断背驰，并建议将已经出现的部分 C 段柱面积乘二估计完整面积。该方法可以作为交易中的经验预测器，但**不等于对未来未知面积的确定性计算**。

对于同向柱面积累计值 S、尚未观察到的非负余量 R：

```text
C_final = S + R
Estimate = 2*S
Error = R - S
```

构造两个世界，它们截至 t 的已知柱体贡献均为 `[1,2]`，S=3，估计都是 6，作为比较的 A 段面积都是 10。世界甲未来没有新增同方向面积，最终 C=3<A；世界乙未来新增 `[4,4,4]`，最终 C=15>A。当前观察完全一致，但最终背驰判定相反。

**严格限制**：这里是非负面积贡献的代数演示，未由真实价格计算 MACD(12,26,9)，也没有递归确认 A/B/C 和对应中枢，故它不反证整套缠论理论；它只表明**面积乘二本身不是未来面积的数学上界、下界或必然值**。

未来应对比同一时点真实可得的数据：面积乘二、斜率预测、条件分布预测，并报告样本外误差、估计区间、级别和交易成本。图像中未确认的精确值不得进入实证。
